# 03 · 간격·레이아웃 (AIP)

## 1. 4px 그리드

`space`: 0 · px(1) · 0-5(2) · 1(4) · 1-5(6) · 2(8) · 3(12) · 4(16) · 5(20) · 6(24) · 8(32) · 10(40) · 12(48) · 16(64) · 20(80) · 24(96) · 32(128).
이름은 4px 배수다(`space.4` = 16px). 13·18·25px 이 나오면 잘못 잡은 것이다.

| 관계 | 간격 |
|---|---|
| 같은 요소 안(아이콘↔라벨, 라벨↔인풋) | 8 |
| 같은 그룹(버튼↔버튼, 체크박스↔체크박스) | 12 |
| 그룹↔그룹(폼 필드 사이) | 20 |
| 블록↔블록(문서 그림 위아래, 카드 그리드) | 24 |
| 섹션 안 큰 덩어리 | 32~48 |
| 랜딩 섹션 사이 | 64(모바일) / 96(lg) |

가까운 것은 가깝게, 다른 것은 멀게. 간격이 위계를 말하게 하고 선은 그다음이다.

## 2. 레이아웃 원시 요소(components/layout.css)

| 클래스 | 무엇 | 기본 |
|---|---|---|
| `.aip-container` | 가운데 정렬 + 반응형 gutter(16/24/32) | max 1440 |
| `--prose` `--sm` `--md` `--lg` `--full` | 폭 단계 | 720+gutter · 640 · 880 · 1120 · 제한 없음 |
| `.aip-stack` | 세로로 쌓고 사이만 띄움 | 16 |
| `.aip-cluster` | 가로 나열 + 줄바꿈 | 8 |
| `.aip-grid` `--2` `--3` `--4` `--auto` | 반응형 열 | 1열 → md 2열 → lg 지정 열 |
| `.aip-gap-1/2/3/4/6/8/12` | 위 셋의 간격 | 이 일곱 단계 밖은 없다 |
| `.aip-section` `--subtle` | 랜딩 섹션 상하 리듬 | 64 / 96 |
| `.aip-hide-below-md` `-lg` | 폭에 따라 숨기기 | 숨기기 전에 드로어·접힘을 먼저 검토 |

## 3. 브레이크포인트

min-width, 모바일 퍼스트. Tailwind 기본과 같다: sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536.

| 폭 | 문서 | MakeAIP | Playground | 헤더 |
|---|---|---|---|---|
| < 768 | 1열. 상단 바(메뉴·브레드크럼) + 사이드바 드로어. TOC 는 본문 위 접힘 | 1열 + 하단 고정 생성 바 | 에디터 / 결과 세로 | 56. 내비는 드로어, 검색은 아이콘 |
| 768~1023 | 위와 같음, gutter 24 | 위와 같음 | 위와 같음 | |
| 1024~1279 | 사이드바 고정 + 본문. TOC 는 본문 위 접힘 | 2열(설정 560 \| 미리보기 sticky) | 좌우 분할 | 64. 내비 노출 |
| ≥ 1280 | 3열: 사이드바 272 \| 본문 720 \| TOC 224 | | | |

## 4. 제품 셸 치수(`size.layout.*`)

| 토큰 | 값 | 무엇 |
|---|---|---|
| `header` / `header-lg` | 56 / 64 | 네 제품 공통 헤더. 제품을 건너도 같은 높이 |
| `sidebar` | 272 | 문서 사이드바 |
| `toc` | 224 | 문서 TOC |
| `column-gap` | 48 | 문서 3열 사이 |
| `config` | 560 | MakeAIP 설정 열 |
| `toolbar` | 48 | Playground 툴바 |
| `drawer` | 320 (최대 85vw) | 모바일 드로어 |
| `indent` | 16 | 사이드바 하위·파일 트리 들여쓰기 |
| `anchor-offset` | 88 | 앵커 이동 시 scroll-margin-top |
| `page-gutter{,-md,-lg}` | 16/24/32 | 화면 좌우 여백 |

### 문서 셸의 계산
`272 + 48 + 720 + 48 + 224 = 1312`, gutter 포함 1376. xl(1280)에서는 본문 열이 `minmax(0, 720)` 이라 줄어든다(최소 약 650). 이 폭에서도 80열 코드는 가로 스크롤로 버틴다. 사이드바는 화면 왼쪽에 붙고 본문+TOC 묶음은 남은 폭의 가운데에 선다. 사이드바 면과 경계선은 셸(`.aip-docs`) 배경으로 그려서, sticky 사이드바 내용이 짧아도 열이 끝까지 이어진다.

## 5. 정렬 규칙

1. 같은 줄의 컨트롤은 같은 높이(`size.control.*`). 헤더 안은 전부 sm(32).
2. 아이콘은 글자 첫 줄 가운데에 맞춘다. 콜아웃 아이콘은 `margin-top: (1lh − 20px) / 2`.
3. 숫자는 오른쪽, 글자는 왼쪽. 가운데 정렬은 빈 상태·히어로만.
4. 그리드 마지막 줄의 빈 칸은 그대로 둔다(늘이지 않는다).
5. 표는 좁은 화면에서 **표만** 가로 스크롤(`.aip-table-wrap`). 페이지 전체가 가로로 밀리면 버그다.
