# 05 · 모션 (AIP)

모션은 **상태가 바뀌었다는 설명**에만 쓴다. 장식 애니메이션·스크롤 연출·반짝임·타이핑 효과는 없다. 예측 가능한 도구는 움직임도 예측 가능해야 한다.

## 1. 토큰

| duration | 값 | 쓰는 곳 |
|---|---|---|
| `fast` | 120ms | hover 색·체크·스위치·탭 밑줄·앵커 링크 표시 |
| `normal` | 180ms | 드롭다운·툴팁·접힘(사이드바 그룹 chevron) |
| `slow` | 240ms | 다이얼로그·드로어 진입 |
| `tooltip-delay` | 400ms | 마우스 hover 후 툴팁이 뜨기까지. 키보드 포커스는 즉시 |
| `feedback` | 1600ms | '복사됨' 같은 확인 상태가 원래대로 돌아가기까지 |
| `toast` | 5000ms | 토스트 자동 닫힘(액션이 있으면 자동으로 닫지 않는다) |

| easing | 값 | 쓰는 곳 |
|---|---|---|
| `standard` | (0.2, 0, 0, 1) | 화면 안에서 바뀌는 것. 기본 |
| `enter` | (0, 0, 0, 1) | 들어오는 것 |
| `exit` | (0.4, 0, 1, 1) | 나가는 것. 진입보다 짧게 |
| `linear` | | 스피너 |

`distance.sm` 4px(드롭다운·툴팁), `distance.md` 8px(다이얼로그).

## 2. 규칙

1. `transition: all` 금지. 바뀌는 속성만 적는다(빌드 lint 가 막는다).
2. `ease-in-out` 같은 키워드 금지. easing 토큰만.
3. 문서 본문의 글자는 움직이지 않는다. 움직이는 것은 크롬(메뉴·다이얼로그·탭 밑줄)뿐이다.
4. 스크롤로 나타나는 리빌 효과를 쓰지 않는다. 문서를 검색해 들어온 사람에게 내용이 늦게 나타나면 안 된다.
5. 스켈레톤은 **정지**해 있다(shimmer 없음). 로딩은 모양으로 알리고 움직임으로 재촉하지 않는다.
6. 스피너는 300ms 가 지나도 안 끝날 때만 보인다(08 §1).

## 3. 모션 축소

`prefers-reduced-motion: reduce` 이면 `fast`·`normal`·`slow` 가 0ms 가 된다(tokens.css). 다이얼로그·드로어·메뉴의 진입 키프레임도 꺼진다. 스피너는 멈추지 않고 느려진다(진행 중이라는 정보는 남긴다). `feedback`·`toast`·`tooltip-delay` 는 움직임이 아니라 시간이라 그대로다.
