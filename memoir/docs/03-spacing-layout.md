# 03 · 간격·레이아웃 (memoir)

## 1. 여백이 구조다
No-Line 시스템에서 간격은 구분선의 대체물이다. base 보다 한 단계 넉넉하게 쓴다.

| 토큰 | px | 언제 |
|---|---|---|
| `1` | 4 | 칩 내부·아이콘 미세 |
| `2` | 8 | 아이콘↔라벨, 칩 사이, 라벨↔인풋, 명령어 행 사이 |
| `3` | 12 | 미리보기 카드 패딩(design-guide), 카드 안 요소 사이 |
| `4` | 16 | 컴포넌트 내부 패딩, 모바일 좌우 |
| `6` | 24 | **리스트 항목 사이(구분선 대신)**, 카드 패딩, 필드 사이, 데스크톱 좌우 |
| `8` | 32 | 카드 묶음 사이, 서브 헤더 아래 첫 콘텐츠 |
| `12` | 48 | 섹션 사이 |
| `16` | 64 | 빈 상태 상하·랜딩 히어로 아래 |
| `24` | 96 | 랜딩 섹션 |

```
[서브 헤더 44]
   ↕ space.8 (32)
[headline 페이지 제목 + display 강조]
   ↕ space.12 (48)
[카드]        ← 카드 사이 space.6 (24), 선 없음
[카드]
   ↕ space.12
[다음 섹션]
```
- 안쪽 패딩 ≤ 바깥 간격(카드 패딩 24 = 카드 사이 24 가 하한).
- 리스트에 `divide-y`·`border-b` 를 쓰고 싶어지면 여백을 8 늘린다.

## 2. 화면 골격 — 헤더 의존 설계 (사이드바 없음)
```
┌ 메인 헤더 60 (sticky) ─ 로고 · [카테고리 ▾] · 검색(필) · [+ New] · 아바타 ┐
├ 서브 헤더 44 (sticky) ─ 필터 칩 / 브레드크럼 / 월 내비 ─────────────────┤
│  콘텐츠 (좌우 24~32, 위 32)                                            │
│                                                        [FAB 56] 우하단 │
└─────────────────────────────────────────────────────────────────────┘
```
- 두 헤더 합 104 = `size.layout.header-stack`. 스크롤 앵커·sticky 패널 top 은 이 값.
- 화면 전환·필터·검색·액션은 전부 헤더에서. 콘텐츠 영역에 툴바를 또 두지 않는다.
- 메인 헤더 배경: 정지 시 `surface.default`, 스크롤 시 `glass.bg-modal` + blur(12). 서브 헤더는 `surface.canvas` 로 헤더와 면 차이.
- 모바일(767 이하): 메인 헤더에 로고·카테고리·검색 아이콘·아바타. 서브 헤더 칩은 가로 스크롤 + `fade-right`. FAB 우하단 16.

### 컨테이너
| 토큰 | 값 | 언제 |
|---|---|---|
| `sm` | 480 | 로그인·회원가입·2FA·프롬프트 모달 |
| `md` | 720 | 단순 메모 카드 리스트·프라이빗 읽기 |
| `lg` | 960 | 일반 메모 에디터 본문(툴바는 전폭) |
| `xl` | 1280 | 코드·명령어·북마크·영상 리스트 |
| `full` | 100% | 캘린더·대시보드 벤토·명령어 와이드 뷰 |
| `prose` | 680 | 에디터 글 한 줄 |

### 좌우 여백
모바일 16 · 768 이상 24 · 1280 이상 32 (`size.layout.page-gutter*`). 기획서 "24~32".

### 브레이크포인트
`sm` 640 (카드 2열) · `md` 768 (헤더 전체 노출, 벤토 2열, 모달↔시트 전환) · `lg` 1024 (벤토 3열, 캘린더 사이드 패널 고정, 에디터 비대칭 여백) · `xl` 1280 · `2xl` 1536.

## 3. 카테고리별 레이아웃 공식 (기획서 5.4)

| 카테고리 | 컨테이너 | 골격 | 서브 헤더 |
|---|---|---|---|
| ☁️ 나의 공간 | full | 제목+날짜 → 오늘 할일(전폭 벤토) → 3열 벤토(코드·명령어·북마크). 모바일 1열 | 없음 또는 날짜 |
| 📅 캘린더 | full | [월간 그리드 1fr \| 패널 320]. 셀 최소 96(모바일 48) | ‹ 2026년 9월 › · 오늘 |
| 📝 일반 메모 | lg | 전폭 툴바 + prose 680 에디터(좌 10% 우 5%). 리스트 없이 즉시 진입 | 폴더 브레드크럼 |
| ✍️ 단순 메모 | md | 텍스트 카드 세로 리스트, 카드 패딩 24, 사이 24 | 정렬·태그 칩 |
| 💻 코드 스니펫 | xl | 카드 리스트(제목+언어 배지 → 코드 블록 아코디언 → 설명 → 태그·날짜) | 언어 칩 |
| ⌨️ 명령어 | full | 한 줄 행 52, 행 사이 8, [플랫폼 배지 \| 명령어 mono \| 설명 \| 복사] | 플랫폼 칩 |
| 🔗 URL 북마크 | xl | 슬림 가로 카드 96 높이, 3열 그리드(모바일 1열) | 태그 칩 + 뷰 전환 |
| 🎬 영상 | xl | 16:9 썸네일 갤러리 3열(md 2열) | 태그 칩 |
| 🔐 보안 | xl | 가로 컴팩트 행 72, 왼쪽 핑크 띠, 잠금 시 블러 | 잠금 상태 + 카운트다운 |
| 🙈 프라이빗 | md | 폴더 타일 160 그리드 → 안에서 태그형 메모 리스트 | 폴더 브레드크럼 |

## 4. 대시보드 벤토
```css
.bento { display: grid; gap: var(--mm-component-bento-gap); grid-template-columns: 1fr; }
@media (min-width: 768px)  { .bento { grid-template-columns: repeat(2, 1fr); } .bento .wide { grid-column: 1 / -1; } }
@media (min-width: 1024px) { .bento { grid-template-columns: repeat(3, 1fr); } }
.bento > * { background: var(--mm-component-bento-bg); backdrop-filter: blur(var(--mm-component-bento-blur)); border-radius: var(--mm-component-bento-radius); padding: var(--mm-component-bento-padding); min-height: var(--mm-component-bento-min-height); }
```
벤토는 `surface.cream` 또는 랜딩 블롭 위에 놓아야 글래스가 보인다. 순백 캔버스 위에서는 투명이 안 보인다.

## 5. 정렬
- 텍스트 좌측. 가운데는 빈 상태·2FA·온보딩만.
- 카드 하단 메타 줄: 왼쪽 태그, 오른쪽 날짜(`label`).
- 헤더 액션 순서: 검색 → New(pill primary) → 아바타. New 는 헤더에서 유일한 로즈.
- 모달 푸터: 우측 정렬, 주 버튼 오른쪽. 모바일 세로 쌓기.
