# 07 · 상태와 피드백 (memoir)

| 상태 | 언제 | 표시 |
|---|---|---|
| 첫 로딩 | 카테고리 진입 | 스켈레톤(카드 3장·행 5개, 같은 자리) |
| 재조회 | 필터 칩 변경 | 기존 유지 + 서브 헤더 아래 2px progress |
| 빈 상태 | 0건 | §2 |
| 저장 중 / 저장됨 | 에디터 자동 저장 | 서브 헤더 `caption` "저장 중…" → "저장됨 · 14:30" |
| 잠김 | 보안 메모 2FA 전 | 미리보기 블러 + 자물쇠 + "인증하고 열기" |
| 인증 세션 만료 임박 | 남은 2분 | 서브 헤더 `status.secure` 배지 카운트다운, 1분 전 토스트 |
| 인증 만료 | | 자동 잠금 + 토스트 "보안 구역이 잠겼어요" |
| 오프라인 | | neutral 배너 "오프라인이에요. 연결되면 저장돼요". 에디터는 계속 쓸 수 있음(로컬 보관) |
| 오류 | 요청 실패 | §3 |
| OG 정보 없음 | 북마크 fetch 실패 | 이미지 자리 zone-deep + 파비콘, 제목은 URL |
| 로그인 필요 | 세션 만료 | 로그인 모달(글래스), 작성 중 내용 보존 |

## 1. 로딩
- 300ms 규칙. 그 안에 오면 아무것도 없다.
- 카드 스켈레톤은 실제 카드 높이(코드 카드 ≈ 320, 북마크 96, 명령어 52).
- 에디터는 스켈레톤 대신 제목·본문 자리에 옅은 플레이스홀더.
- 북마크 OG fetch 는 카드 먼저 그리고 이미지 자리만 shimmer.
- 버튼 로딩은 그 버튼만.

## 2. 빈 상태 (design-guide: 빈 화면도 안내한다)
```
[일러스트 또는 아이콘 48 + 배경 원 80 cream]   ← 위 space.16
[display-sm 36 또는 title-lg 24]  "아직 코드 스니펫이 없어요"
[body secondary]                   "자주 쓰는 함수를 저장해 두면 검색 한 번에 찾아요"   ← 아래 space.6
[primary md]                       "첫 스니펫 만들기"
```
| 카테고리 | 제목 | 액션 |
|---|---|---|
| 나의 공간 | "오늘은 아직 비어 있어요" | "할 일 추가" + "즐겨찾기 둘러보기" link |
| 캘린더(날짜) | "이 날엔 아무것도 없어요" | "메모 추가" |
| 일반 메모 | (빈 상태 없음, 바로 에디터) | |
| 단순 메모 | "짧게 적어 둘 게 있나요?" | "메모 쓰기" |
| 코드 | "아직 코드 스니펫이 없어요" | "첫 스니펫 만들기" |
| 명령어 | "자주 쓰는 명령어를 모아 두세요" | "명령어 추가" |
| 북마크 | "저장한 링크가 없어요" | "링크 추가" (URL 붙여넣기 인풋 바로 노출) |
| 영상 | "본 영상을 기억해 두세요" | "영상 추가" |
| 보안 | "보안 메모가 없어요" | "보안 메모 만들기" (2FA 먼저) |
| 프라이빗 | "폴더를 만들어 시작해요" | "새 폴더" |
| 검색 결과 | "‘{검색어}’ 에 맞는 메모가 없어요" | 없음 |
| 필터 결과 | "이 조건에 맞는 항목이 없어요" | "필터 지우기" |

큰 빈 상태(카테고리 첫 진입)는 `display-lg` 로 에디토리얼하게 크게(design-guide "Use display for empty states"). 카드 안 빈 상태는 `title-lg`.

## 3. 오류
| 수준 | 표시 |
|---|---|
| 필드 | 밑줄 red 2px + `caption` `text.danger` + 아이콘 12 |
| 2FA | PIN shake + 칸 밑줄 red + "코드가 맞지 않아요 (2/5)". 5회 실패 시 10분 잠금 배너 |
| 동작 | 토스트 "저장하지 못했어요 · 다시 시도" 6초 |
| 섹션(벤토) | 그 박스만 아이콘 + "불러오지 못했어요" + ghost sm 다시 시도 |
| 페이지 | 빈 상태 형태 + 오류 ID `caption` tertiary + "다시 시도"/"나의 공간으로" |
| 에디터 저장 실패 | 서브 헤더 `caption` `text.danger` "저장 실패 · 다시 시도". 내용은 로컬 보존 |

문구: [무엇이] + [왜] + [어떻게]. 사용자 탓 금지. 코드는 작게 뒤에.
오류(빨강)와 보안 상태(핑크)를 섞지 않는다. 2FA 실패는 오류(빨강), 잠금 상태는 보안(핑크).

## 4. 확인 (되돌릴 수 없는 것만)
| 행동 | 확인 |
|---|---|
| 메모 삭제 | 없음. 토스트 "삭제됨 · 되돌리기" 6초(휴지통 30일) |
| 폴더 삭제(내용 있음) | Prompt 모달: "‘{폴더}’ 와 메모 12개를 삭제할까요?" · "삭제" danger |
| 보안 메모 삭제 | 2FA 재확인 + 모달 |
| 2FA 해제·비밀번호 변경·탈퇴 | 모달 + 현재 비밀번호 + 이름 입력(탈퇴) |
| 에디터 이탈(미저장) | 자동 저장이라 없음. 저장 실패 상태면 "저장되지 않은 내용이 있어요" 확인 |

## 5. 성공
| 행동 | 피드백 |
|---|---|
| 자동 저장 | `caption` "저장됨 · 14:30" 1.5초 fade |
| 메모 만들기 | 새 카드가 목록 상단에 fade-in, 토스트 없음 |
| 복사(코드·명령어) | 버튼 아이콘 check 1.5초 + 툴팁 "복사됨" |
| 즐겨찾기 | ★ 채움 즉시, 토스트 없음 |
| 2FA 성공 | 블러 걷힘 600ms + 서브 헤더 "보안 구역 · 14:32 까지" |
| 북마크 추가 | 카드 생성 + OG 채워지면 이미지 fade-in |

## 6. 비활성 vs 숨김
- 2FA 미설정 사용자의 보안 카테고리: **보이되 진입 시 설정 안내**. 숨기지 않는다.
- 잠긴 상태의 편집 버튼: 비활성 + "인증 후 편집할 수 있어요".
- 관리 기능 없음(개인 서비스). 권한 개념 없음.

## 7. UX 문구
- 해요체. 친근하되 가볍지 않게. "저장했어요" / "삭제됐어요".
- 버튼은 동작: "만들기" "저장" "삭제" "인증하기" "열기". "확인/OK" 금지.
- 카테고리 이름은 기획서 그대로: 나의 공간 · 캘린더 · 일반 메모 · 단순 메모 · 코드 스니펫 · 명령어 메모 · URL 북마크 · 영상 메모 · 보안 메모 · 프라이빗. 이모지는 드롭다운·헤더에만, 본문 문장에는 안 넣는다.
- 보안 문구는 안심시키되 과장 금지: "이 구역은 2FA 로 보호돼요" (O) / "군사급 암호화" (X).
- 미국 SaaS 톤 금지(기획서): "Get started", "Awesome!" 같은 영문 감탄 없음. 단, 메타 라벨(`OCT 24, 2023`, `JAVASCRIPT`)의 라틴 대문자는 에디토리얼 장치로 허용.
- 날짜 `2026.09.19`, 시간 24시간제, 상대 시간 7일까지.

| 이렇게 (O) | 이렇게 말고 (X) |
|---|---|
| 나의 공간 | 대시보드, 홈 |
| 보안 구역 | 시큐어 존, 볼트 |
| 인증하기 | 언락, 2FA 진행 |
| 즐겨찾기 | 핀, 북마크(북마크는 URL 카테고리) |
| 다시 시도 | 재시도 |
| 저장됨 | 세이브 완료 |
