# 11 · 데이터 시각화 (memoir)

memoir 에 차트는 거의 없다. 대시보드 통계와 캘린더 히트맵 정도. 소박하게, 종이 위 연필처럼.

## 1. 색
| 토큰 | 언제 |
|---|---|
| `chart.categorical.1~5` | 카테고리별 메모 수 비교(pink·periwinkle·amber·green·neutral). 5개 넘으면 기타 |
| `chart.heat.0~4` | 캘린더 활동 히트맵. paper-deep → pink.100 → 200 → 300 → 400 |
| `chart.grid` `axis` `label` | neutral.200 / 500 / 700 |
| `brand.periwinkle` | 단일 시리즈 선(주간 작성 수) |

## 2. 차트 고르기
| 묻는 것 | 차트 |
|---|---|
| 카테고리별 메모 수 | 가로 막대(라벨이 길다), radius 4, 값 직접 라벨 |
| 주간·월간 작성 추이 | 선 1.5px 페리윙클, 점 없음, 격자 가로 3줄 |
| 활동 밀도 | 캘린더 히트맵(셀 배경 heat.N) 또는 52주 잔디 12px 셀 gap 3 |
| 할일 완료율 | 링 1개, 굵기 8, 트랙 zone-deep, 채움 로즈, 가운데 `title` 숫자 |
| 저장 용량·비율 | 가로 누적 막대 1개 |

파이 금지. 축·범례 최소. 숫자를 직접 적는다.

## 3. 규격
축 라벨 `caption` 12 `chart.label`, 축선 없음, 격자 `chart.grid` 1px 가로만, 막대 간격 40%, 툴팁은 툴팁 규격(ink 면). 높이: 벤토 안 160, 통계 페이지 240. 애니메이션 첫 렌더 `normal` 200 한 번.

## 4. 접근성
색 + 숫자 라벨. 히트맵 셀 툴팁 "9월 19일 · 메모 3개". `<figcaption>` 한 문장 + 숨긴 표.
