# 16 · 상황 사전 — "이럴 땐 이렇게" (memoir)

00 결정표가 "무엇을 쓸까"라면, 이 문서는 "이 상황이 왔는데 어떻게 하지"다. 없는 상황은 가장 비슷한 항목을 따르고 §끝 절차로 추가한다.

## A. 면·구획 (No-Line 에서 가장 자주 막힌다)

| 상황 | 이렇게 |
|---|---|
| 리스트 항목 사이에 선을 긋고 싶다 | 24 여백. 좁아 보이면 32. hover 시 항목이 흰 면으로 떠오른다 |
| 카드와 카드가 구분이 안 된다 | 카드가 `zone` 위에 있는지 확인. 캔버스(paper) 위 흰 카드는 1.04:1 라 안 보인다 |
| 카드 안에 구획이 필요하다 | `zone-deep` 면(패딩 12·radius 8) 또는 16 여백. 카드 안 카드 금지 |
| 흰 카드 안에 흰 인풋 | filled 인풋은 `zone-deep`. underline 인풋은 밑줄이 경계 |
| 벤토(글래스)가 안 보인다 | 뒤가 흰색. 크림·블롭 위로 옮긴다 |
| 표가 필요하다 | zebra(`zone`) 또는 hover 흰 면, 세로선 없음. 4열 이상 모바일은 카드 |
| 캘린더 셀 경계 | 유일하게 선 허용 `border.default` |
| 헤더와 콘텐츠 경계 | 헤더 `default`, 서브 헤더 `canvas`, 콘텐츠 `zone`. 스크롤 시 헤더 글래스 + `border.subtle` |
| 모달 안 섹션 구분 | 24 여백 + `title-sm`. 선 없음 |
| 이미지가 흰 배경이라 카드와 경계가 안 보인다 | `border.ghost`(15%) 허용. 또는 `zone-deep` 배경 위 `object-fit: contain` |
| 코드 블록이 카드 안에서 튄다 | 정상. 코드는 항상 ink 면(정체성). radius 12 |
| 접근성 요구로 경계선이 필요 | `border.ghost`. `prefers-contrast: more` 오버라이드(13 §8) |
| 드래그 앤 드롭 대상 표시 | 드롭 라인 2px indigo(파랑 = 상호작용) |
| 선택된 카드 표시 | `selected-bg`(pink.50) + 좌상단 체크. 테두리 없음 |

## B. 색

| 상황 | 이렇게 |
|---|---|
| 핑크 버튼(`bg-primary`)에 흰 글자 | 금지(2.33). 로즈 `action.primary`. 핑크가 꼭 필요하면 wine 글자 |
| 강조 단어를 핑크로 | 로즈 `text.brand`. 핑크 글자는 0건 |
| 아이콘을 핑크로 | ★ 채움만 `brand.pink`. 나머지는 tertiary/secondary |
| 파랑을 배경 장식으로 | 안 된다. 파랑 = 클릭. 장식은 블러시·크림 |
| 활성 메뉴 흰 글자 2.95 가 걸린다 | 라벨 14/600 + 체크 아이콘 유지. 엄격하면 `surface.interactive` 를 indigo 로 오버라이드 |
| 캡션을 크림 면에 놓는다 | `text.tertiary`(700) 는 크림 위 6.2 통과. 600 이하 금지 |
| 오류를 핑크로 표시하고 싶다 | 오류는 `status.danger`(빨강). 핑크는 보안 상태만 |
| 보안 경고(만료 임박) | `status.secure` 배지 + 카운트다운. 빨강 아님 |
| 성공 배지 색 | `status.success` 옅은형. 초록은 상태에만 |
| 카테고리 식별색을 카드 배경에 | 금지. 드롭다운 아이콘 원·벤토 헤더 점만 |
| 언어 배지 색이 필요 | 50~100 단계 옅은 면 + 700~800 글자. 채도 높은 배지 금지 |
| 다크에서 로즈 버튼이 죽는다 | 토큰이 핑크 + wine 으로 바꾼다. 강제하지 않는다 |
| 다크 태그(blush) | pink.300 + wine 자동 |
| 링크가 본문에서 안 보인다 | indigo + 밑줄. 본문 안 링크는 항상 밑줄 |
| 히트맵 셀 글자 | heat.3·4 는 wine, 0~2 는 ink |
| 코드 하이라이트 색을 바꾸고 싶다 | `color.code.*` 토큰만. 하이라이터 테마를 토큰으로 매핑 |

## C. 글자

| 상황 | 이렇게 |
|---|---|
| 한글이 얇고 어색하다 | Pretendard 폴백이 빠졌다(02 §1). `font-family` 에 두 번째로 |
| 제목이 3줄 | 2줄 clamp + 툴팁. 제목 인풋은 자동 높이 |
| 메타를 한글로 써야 한다("2023년 10월 24일") | `caption`(12/500). `label` 대문자 자간은 라틴 메타(OCT 24, 2023)에 |
| 날짜 표기 | UI `2026.09.19`, 카드 메타 `OCT 24, 2023` 허용, 상대 시간 7일 |
| 명령어가 한 줄을 넘는다 | 1줄 말줄임 + 클릭 확장(전체 mono 블록). 행 높이 52 유지 |
| 코드 줄이 길다 | 가로 스크롤 기본, 툴바에 "줄바꿈" 토글 |
| 에디터 글자 크기 조절 요청 | `editor` 16 고정. 확대는 브라우저 줌 |
| 강조 단어 두 개 | 하나만 로즈. 나머지 600 굵기 |
| 플레이스홀더가 라벨 대신 | 항상 라벨(`label` 대문자) 위에. 플레이스홀더는 예시 |
| 숫자 정렬(통계) | `numeric` 없음 → 링·막대 라벨은 `title`/`caption`, 자릿수 정렬 필요 없음 |
| 영어 UI 문구 | 메타 라벨(JAVASCRIPT, OCT)만. 버튼·안내는 한국어 해요체 |
| 12px 아래 글자 | 없다. 줄 번호 11 만 예외 |

## E. 컴포넌트 조합

| 상황 | 이렇게 |
|---|---|
| 카드 전체 클릭 + ★ + ⋯ | 카드 클릭 = 열기, ★·⋯ 는 `stopPropagation`. 그 이상 버튼은 상세로 |
| 태그가 5개 | 3개 + "+2". 클릭 확장 |
| 태그 입력 | 칩 + X, Enter/쉼표로 추가, 자동완성 드롭다운 |
| 필터 칩 다중 vs 단일 | 태그·언어 = 다중(`aria-pressed`), 정렬·뷰 = 단일(세그먼트) |
| 드롭다운 항목 50개(태그) | 검색 인풋 상단 + 최대 320 스크롤 |
| 모달 안에서 선택(폴더) | 모달 안 드롭다운 `z-index.popover`. 모달 위 모달 금지 |
| 프롬프트 모달에 인풋 2개 | Prompt 는 1개. 2개부터 Modal |
| 시트 안 긴 폼 | 본문 스크롤, 헤더·CTA 고정, 90vh |
| 툴팁이 터치에서 안 뜬다 | 탭 → 팝오버 |
| 아이콘 버튼 4개 나란히(헤더) | 최대 3 + ⋯ |
| 스켈레톤 개수 | 실제와 같게. 코드 카드 3(높이 320), 명령어 5, 북마크 6 |
| 체크박스 vs 스위치 | 제출·선택 = 체크박스(할일·다중 삭제), 즉시 반영 = 스위치(2FA·알림·다크) |
| 삭제 확인 | 메모 = 확인 없이 되돌리기 토스트. 폴더(내용 있음)·보안 메모·탈퇴 = 모달 |
| 복사 피드백 | 아이콘 check 1.5초 + 툴팁 "복사됨" + `role="status"` |
| 코드 블록 접힘 기준 | 240 넘으면 접힘 + 페이드 + "더 보기". 12줄 이하는 안 접음 |
| 명령어 그룹이 없다 | 그룹 라벨 생략, 행만 |
| 영상 URL 이 유튜브가 아니다 | 썸네일 없으면 `zone-deep` + play 아이콘 + 도메인 |
| 북마크 OG 없음 | `zone-deep` + 파비콘 16, 제목은 URL 호스트 |
| 폴더 깊이 5단계 | 브레드크럼 "… " 접기, 최대 깊이 제한은 제품 결정 |
| 캘린더 셀에 이벤트 6개 | 3 + "+3", 클릭 → 패널 |
