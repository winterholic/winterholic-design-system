# 03 · 모바일·태블릿 레이아웃

## 구간
320~374 작은 휴대폰 · 375~430 일반 · 431~599 큰 휴대폰 · 600~1024 태블릿. breakpoint 토큰 `375 / 431 / 600 / 1025`(min-width). 기본 스타일이 320 기준.

## 장면 맞춤 `fitScene(vw, vh)`
- **cover**(뷰포트 가로세로비 ≤ 0.62): 9:16 장면이 화면을 채운다. 남는 폭은 좌우를 트리 중심으로 자른다. 트리 폭 ≤ 장면 폭 70% 라 잘리지 않는다.
- **stage**(> 0.62, 태블릿): 높이를 꽉 채운 가운데 9:16 무대 + 같은 배경을 흐리게 깐 양옆 채움. **UI 도 무대 열 안**에 둬 카드가 옆으로 퍼지지 않는다. 단순 확대 금지.

## 브라우저 변수
- 높이는 `visualViewport`(동적 주소창·키보드 반영, `useViewport`). `100vh` 를 쓰지 않는다(`dvh`·`visualViewport`).
- safe-area: 위·아래 UI 는 `env(safe-area-inset-*)` 로 보호. `viewport-fit=cover` 필수.
- 시트: 최대 86dvh, 본문만 스크롤, `overscroll-behavior: contain`.
- 스크롤 충돌: 질문 패널은 내부 스크롤(`max-height 76%`), 장면 자체는 스크롤하지 않는다.

## 검증 뷰포트(실제 Chrome, 흐름 전체)
320×640 · 360×800 · 390×844 · 430×932 · 768×1024 · 820×1180. 각 화면에서 가로 넘침 0, 터치 영역 44px 미만 0, 글자 잘림 0, 콘솔 오류 0 을 요구한다(`scripts/verify-ui.mjs`, 서비스 저장소).
