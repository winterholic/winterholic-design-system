# 09 · 운영

## 공개/비공개 경계
| 공개(이 저장소) | 비공개(Merrivoo) |
|---|---|
| 토큰·타이포·레이아웃 규칙·컴포넌트·테마 | 서비스 화면·흐름 |
| Scene/Tree/Ornament 규격·엔진·검증기·가공 도구 | 실제 세계관·트리 콘텐츠, 상용 일러스트 |
| CC0 데모 에셋·문서·재현 테스트 | 질문·궁합 점수 로직, 카피 |
| — | API·DB·배포 설정, 폰트 파일 |
공개 → 비공개 참조 없음. 비공개가 공개를 vendor 로 가져온다. 공개에 넣기 전 확인: 비밀·개인 경로·라이선스 불명 에셋·서비스 파일 참조.

## 버전
semver. 토큰 이름 변경·삭제, 엔진 출력 형태 변경, 레지스트리 class 삭제 = major. 토큰 추가·컴포넌트 추가 = minor. 값 보정 = patch. 매니페스트 `version` 은 에셋 단위로 올린다.

## winterholic-base 와 다른 점
시맨틱 이름은 계승, 값·접두(`mv`)·breakpoint(휴대폰 4구간)·서체(display 세리프 추가)·그라데이션 허용(스크림·금박, 버튼 배경은 여전히 금지)·장면 레이어·세계관 테마·엔진은 새로 설계했다. base 의 "카드 안 카드 금지" 는 유지(질문 패널과 선택 카드는 형제).

## 알려진 한계
iOS 사파리·인앱 브라우저 실기기 미검증. 마루부리 라이선스 직접 확인 문구 미확보. 장식이 추가될 때 기존 장식 위치가 조금 바뀔 수 있다(결정적이지만 입력이 바뀌므로). 장식 50개 초과·나뭇가지처럼 가는 트리는 overflow 로 넘긴다.
