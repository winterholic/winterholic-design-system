# 03 · 간격·레이아웃 (notting)

## 1. 4px 그리드

모든 margin·padding·gap 은 `space.*` 중 하나다. 이름은 4px 배수(`space.4` = 16px).

| 토큰 | px | 언제 |
|---|---|---|
| `0-5` | 2 | 블록 상하 패딩, 근거 칩 간격, 토글 안쪽 |
| `1` | 4 | **블록 사이 기본 간격**, 배지 내부, 드롭다운 안쪽 패딩, 인라인 툴바 패딩 |
| `1-5` | 6 | 인풋↔도움말, 트리 항목 내부 간격, 툴팁 상하 |
| `2` | 8 | **밀접한 것 사이**: 아이콘↔라벨, 라벨↔인풋, 툴바 버튼 사이, 보드 카드 사이, 속성 행 gap |
| `3` | 12 | 컴포넌트 내부 패딩(sm 버튼 좌우·리스트 아이템 상하·이슈 카드), 슬래시 메뉴 아이콘↔글자, 카드 제목↔본문 |
| `4` | 16 | **기본 단위**: md 컨트롤 패딩, 폼 필드 사이, 콜아웃·코드 블록·AI 답변·패널 패딩, 트리 들여쓰기, 모바일 여백 |
| `5` | 20 | 카드 패딩(기본), 문서 h3 위 여백 |
| `6` | 24 | 큰 카드·모달 패딩, 문서 h2 위 여백, 제목↔첫 블록, 블록 들여쓰기, 패널 섹션 사이 |
| `8` | 32 | 문서 h1 위 여백, 블록 gutter, 섹션 내부 그룹 사이, 앱 섹션 사이(모바일) |
| `10` | 40 | 폼 섹션 사이 |
| `12` | 48 | 앱 섹션 사이(데스크톱) |
| `16` | 64 | 랜딩 섹션 사이(모바일) |
| `20` | 80 | 에디터 상단 여백(커버 없을 때), 랜딩 히어로 상하 |
| `24` | 96 | 에디터 좌우 여백(데스크톱, 컬럼 밖), 랜딩 섹션 사이(데스크톱) |
| `32` | 128 | 에디터 하단 여백(마지막 블록 아래), 랜딩 대형 섹션 |

13px, 18px, 25px 이 나오면 잘못 잡은 것이다. 가까운 스케일로 올림한다.

## 2. 간격 고르는 원칙 — 가까운 것은 가깝게

간격은 관계의 거리다. 같은 그룹은 좁게, 다른 그룹은 넓게. 세 단계면 충분하다.

```
문서 안                           앱 UI 안
# 제목            ← 32 위        [라벨]        ← 8
본문 문단                         [  인풋  ]
본문 문단         ← 4 사이                     ← 16
## 제목           ← 24 위        [라벨]
본문                              [  인풋  ]
                                              ← 32
```

- 안쪽 패딩 ≤ 바깥 간격. 카드 패딩 20 인데 카드 사이가 12 면 카드가 붙어 보인다. 예외: 보드 카드(패딩 12, 사이 8) — 같은 컬럼 안 카드는 한 묶음이다.
- 세로 리듬은 한 화면에서 세 값 이하(예: 8 · 16 · 32).
- 컴포넌트 안에서는 `padding`, 컴포넌트 사이에서는 부모의 `gap`. 자식에 `margin-bottom` 을 주지 않는다. **문서(`.nt-doc`)만 예외**로 `* + *` 마진 규칙을 쓴다 — 블록이 동적으로 늘고 줄어 gap 보다 마진이 안정적이다.

## 3. 화면 골격

### 앱 셸 — 3열
```
┌ 사이드바 260 ┬ 페이지 툴바 48 ────────────────────────────┬ 패널 320 ┐
│ canvas       │ canvas · 브레드크럼 · 저장 상태 · 공유 · ⋯  │ canvas   │
│ 페이지 트리  ├─────────────────────────────────────────────┤ Ask /    │
│              │                                             │ 속성 /   │
│              │      default(흰) 에디터 컬럼 760, 가운데      │ 백링크 / │
│              │      ← gutter 32 │ 블록 … │                  │ revision │
│              │                                             │          │
└──────────────┴─────────────────────────────────────────────┴──────────┘
```

| 폭 | 사이드바 | 패널 | 에디터 |
|---|---|---|---|
| **2xl (1536 이상)** | 고정 260 | 고정 320 | 760 가운데, 남는 폭은 좌우 여백 |
| **xl (1280~1535)** | 고정 260 | 열면 고정 320, **에디터 여백이 줄어든다**(1280 − 260 − 320 = 700 → 에디터 컬럼 700 으로 축소 허용, 본문 폭 660) | |
| **lg (1024~1279)** | 고정 260 | **드로어**(오버레이, 320) | 760 또는 남는 폭 |
| **md (768~1023)** | 드로어 260 | 드로어 | 전폭 − gutter 24 |
| **모바일 (< 768)** | 드로어(전폭 − 56) | 바텀시트 | 전폭 − gutter 16, 블록 gutter 는 **숨김**(핸들은 길게 누르기) |

- 사이드바를 접으면 완전히 숨긴다(`sidebar-collapsed` 0). 아이콘 레일 없음. 펼침 버튼은 툴바 맨 왼쪽.
- 페이지 툴바는 헤더(56/64)보다 낮은 48. 문서에 자리를 양보한다. 랜딩·설정처럼 문서가 아닌 화면은 헤더 64.
- 에디터 컬럼은 `size.layout.editor` 760 = prose 720 + 좌우 20. "넓게" 설정이면 `editor-wide` 1080(표·보드가 많은 문서).
- 블록 gutter 32 는 에디터 컬럼 **밖** 왼쪽에 붙는다. 핸들(⋮⋮)과 + 가 여기 산다. 컬럼 폭을 잡아먹지 않는다.

### 컨테이너 (문서가 아닌 화면)
| 토큰 | px | 언제 |
|---|---|---|
| `container.sm` | 640 | 로그인·온보딩·단일 폼·확인 |
| `container.md` | 768 | 설정 |
| `container.lg` | 1024 | 랜딩·검색 결과 |
| `container.xl` | 1280 | **이슈 목록·보드·대시보드·왕복 보고서** |
| `container.2xl` | 1440 | 와이드 보드 |
| `container.prose` | 720 | 문서 본문 한 줄 폭 |

```css
.page { max-width: var(--nt-size-container-xl); margin-inline: auto; padding-inline: var(--nt-size-layout-page-gutter); }
@media (min-width: 768px)  { .page { padding-inline: var(--nt-size-layout-page-gutter-md); } }
@media (min-width: 1024px) { .page { padding-inline: var(--nt-size-layout-page-gutter-lg); } }

.editor { max-width: var(--nt-size-layout-editor); margin-inline: auto; padding: var(--nt-component-editor-padding-top) var(--nt-space-5) var(--nt-component-editor-padding-bottom); }
.editor--wide { max-width: var(--nt-size-layout-editor-wide); }
```

| 화면 | 토큰 | px |
|---|---|---|
| 모바일 (< 768) | `layout.page-gutter` | 16 |
| 태블릿 (768 이상) | `layout.page-gutter-md` | 24 |
| 데스크톱 (1024 이상) | `layout.page-gutter-lg` | 32 |

### 고정 요소
| 요소 | 토큰 | px |
|---|---|---|
| 페이지 툴바 | `layout.page-toolbar` | 48 |
| 헤더(랜딩·설정) 모바일 / 데스크톱 | `layout.header` / `header-lg` | 56 / 64 |
| 사이드바 | `layout.sidebar` | 260 |
| 우측 패널 | `layout.panel` | 320 |
| 커버 이미지 데스크톱 / 모바일 | `layout.cover` / `cover-sm` | 240 / 160 |

| 그리드 gap 모바일 / 데스크톱 | `layout.grid-gap` / `grid-gap-lg` | 16 / 24 |

### 브레이크포인트 (min-width, 모바일 퍼스트)
| 이름 | px | 대표 전환 |
|---|---|---|
| `sm` | 640 | 1열 → 2열 카드 |
| `md` | 768 | gutter 24, display 축소 해제, 툴바에 브레드크럼 전체 표시 |
| `lg` | 1024 | **사이드바 고정**, gutter 32, 블록 gutter 표시 |
| `xl` | 1280 | 컨테이너 최대, 패널 고정 가능 |

## 4. 대표 레이아웃 공식

### 에디터 페이지
```
[커버 240 (선택)]
[아이콘 80 (선택), 커버 위로 −40 겹침]              ← 위 여백: 커버 있으면 32, 없으면 80
[prose-title]                                        ← 아이콘↔제목 16
[속성 행들 (선택): 라벨 140 · 값]  각 행 32, 사이 0, 구분선 subtle
[첫 블록]                                            ← 제목(또는 속성)↔첫 블록 24
[블록] ← 4 → [블록] …
[마지막 블록 아래 128 클릭 영역]
```

### 우측 패널
```
헤더 48: 탭(Ask · 속성 · 백링크 · revision) sm 세그먼트 · 닫기 X
본문 패딩 16, 섹션 사이 24, 섹션 제목 heading-4 또는 overline
```

### 카드 그리드 (검색 결과·대시보드 위젯)
```css
.grid { display: grid; gap: var(--nt-size-layout-grid-gap); grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); }
@media (min-width: 1024px) { .grid { gap: var(--nt-size-layout-grid-gap-lg); } }
```

### 보드
```
가로 스크롤 컨테이너, 컬럼 280 고정, 컬럼 사이 16, 컬럼 패딩 8, 카드 사이 8
컬럼 헤더 40: 상태 아이콘 + 이름 + 개수(caption) + 우측 + 버튼
```

### 폼
- 라벨 위, 인풋 아래. 라벨↔인풋 8, 인풋↔도움말 6, 필드↔필드 16, 섹션↔섹션 40.
- 폼 최대 폭 `container.sm`(640). 내보내기 옵션 모달은 `modal.width-md` 560.
- 제출 버튼: 우측 하단(데스크톱), 전폭 lg(모바일).

### 랜딩
- 섹션 상하 64(모바일) / 96(데스크톱). 히어로 80 이상.
- 컨테이너 `container.lg`(1024).

## 5. 정렬 규칙

- 텍스트는 왼쪽 정렬. 가운데 정렬은 랜딩 히어로·빈 상태·확인 다이얼로그에서만. 문서 본문은 가운데 정렬 옵션이 없다.
- 숫자 열은 오른쪽 정렬 + `numeric`.
- 버튼 그룹: 데스크톱 우측 정렬, 주 버튼 오른쪽. 모바일 세로 쌓기는 주 버튼 위.
- 속성 행: 라벨 왼쪽 140 고정, 값 왼쪽 정렬. 값이 비면 `placeholder` 색 "비어 있음".
- 블록 핸들은 블록의 **첫 줄** 세로 중앙에 맞춘다(여러 줄 문단이어도).

## 6. 하지 말 것 → 대신

| ❌ | ✅ |
|---|---|
| 문단 사이 16px | `editor.block-gap` 4 + 블록 패딩 2. 문서는 촘촘하다 |
| 문서 제목 바로 아래 첫 블록 | 24 |
| 에디터 폭 900 임의 | 760 또는 넓게 1080 |
| 블록 핸들이 본문 폭을 잡아먹음 | gutter 32 는 컬럼 밖 |
| 사이드바를 아이콘 레일로 접기 | 완전히 숨김 + 툴바 펼침 버튼 |
| xl 에서 패널 열면 에디터가 720 미만으로 | 660 까지 허용, 그 아래면 패널을 드로어로 |
| 모바일 좌우 여백 8px | 16 고정 |
| 자식마다 `margin-bottom` (UI) | 부모 `gap`. 문서(`.nt-doc`)만 마진 |
| 보드 카드 사이 16 | 8. 같은 컬럼은 한 묶음 |
| 속성 라벨 폭을 내용에 맞춤 | 140 고정. 값이 세로로 정렬돼야 훑어진다 |
