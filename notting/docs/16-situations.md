# 16 · 상황 사전 — "이럴 땐 이렇게" (notting)

00 결정표가 "무엇을 쓸까"라면, 이 문서는 "이 상황이 왔는데 어떻게 하지"다. A~J 는 범용, **K~N 은 notting 도메인**(에디터 · Markdown 왕복 · AI·근거 · 이슈·revision). 여기서 답이 나오면 다른 문서를 열 필요가 없다.

## A. 글자

| 상황 | 이렇게 |
|---|---|
| 페이지 제목이 두 줄 | 허용(tight 1.2). 세 줄이면 그대로 두되 브레드크럼은 1줄 말줄임 |
| 트리 항목 이름이 길다 | 1줄 말줄임 + 툴팁. 폭은 안 늘린다 |
