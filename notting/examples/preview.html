Notting 초기 기획 및 설계

1. 결론

Notting 은 범용적인 Notion 복제가 아니다. 첫 제품은 편집·소유권·근거 세 계약에 집중한다. 본문은 16px 에 행간 1.7, 단어 중간에서 줄이 끊기지 않는다.

7.1 lossless 의 정확한 정의

  • Semantic round-trip: AST 비교에서 의미 동등
  • Notting bundle round-trip: 고유 블록·속성·ID 까지 복원
    • 사이드카는 Markdown 에 표현할 수 없는 것만
  • fixture 기반 왕복 테스트
  • Tiptap adapter
지원하지 않는 요소는 손실을 숨기지 않는다.

인라인 코드 schemaVersion 은 코럴, 링크는 밑줄과 verdigris. 근거 칩은 문장 끝에 붙는다12

8.2 Document AST

type Block = {
  id: string;           // 안정 ID
  type: BlockType;
  attrs: Record<string, unknown>;
  children?: Block[];   // 최대 5단계
};
✦ AI 요약: AST 는 editor·API·Markdown·search 가 공유하는 제품 계약이다.
plain Markdown 으로 내보내면 이 콜아웃은 인용으로 대체된다.
