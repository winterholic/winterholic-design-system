# 03 · 간격·레이아웃 (stock-gosu)

## 1. 4px 그리드 (정보 밀도 높은 화면용 촘촘한 단계)

| 토큰 | px | 언제 |
|---|---|---|
| `0-5` | 2 | 세그먼트 트랙 안쪽, 아이콘 미세 조정 |
| `1` | 4 | 배지 내부, 화살표↔숫자, 종목명↔시장 태그 |
| `1-5` | 6 | 라벨↔인풋, 버튼 아이콘↔라벨 |
| `2` | 8 | 리스트 행 안 세로 간격(종목명↔메타), 필터 칩 사이 |
| `2-5` | 10 | 리스트 행 상하 패딩 |
| `3` | 12 | 카드 안 요소 사이, 표 셀 좌우 |
| `4` | 16 | **기본**. 컴포넌트 내부 패딩, 컴포넌트 사이, 모바일 그리드 gap |
| `5` | 20 | 카드 패딩, 모바일 좌우 여백, 행 좌우 패딩 |
| `6` | 24 | 카드 묶음 사이, 페이지 섹션 gap, 태블릿 좌우 여백 |
| `8` | 32 | 큰 구획 사이, 데스크톱 좌우 여백 |
| `12` | 48 | 화면 안 큰 구획 |
| `16` | 64 | 온보딩·빈 화면 상하 |

13px·27px 이 나오면 잘못 잡은 것이다. 4 그리드에서 가장 가까운 단계를 고른다. 기존 `--space-16` 같은 이름은 `legacy-aliases.css` 가 `space.4` 로 연결한다.

## 2. 간격 결정 규칙 — 어디에 무엇을
```
[종목명 KOSPI]         ← space.1 (4)   이름과 태그는 한 덩어리
[삼성전자 · 005930]    ← space.2 (8)   같은 행 안 두 줄
────────────────      ← 행 상하 space.2-5 (10), 구분선 border.default
[카드 패딩 20]
[카드]  ← space.6 (24) → [카드]         카드 묶음
[섹션]  ← space.8 (32) → [섹션]
```
- 그룹 내부 여백 < 그룹 사이 여백. 항상.
- 세로 리듬은 8 배수(8·16·24·32). 세 값 이내로.
- 화면이 넘치면 줄이는 건 여백이 아니라 정보량이다(기존 FDS 규칙).
- 컴포넌트 사이는 부모 `gap`, 안쪽은 `padding`. 자식 `margin-bottom` 금지.

## 4. 대표 레이아웃 공식

### 앱 셸
```
lg 이상: [sticky 상단 탐색 64] [보조 탐색 48] [콘텐츠 gutter 32, max 1180]
md:      [상단 탐색 64 + 햄버거]  [콘텐츠 gutter 24]
모바일:  [문맥 헤더 56] [콘텐츠 gutter 20] [하단 탭바 56 + safe-area]   더보기는 바텀시트
```
콘텐츠 상단 여백 `space.6`. 페이지 제목(`title-1` + 설명) 아래 `space.6`(`page-header.margin-bottom`).
모바일 본문 하단 패딩 = 탭바 56 + `space.4` (토스트·CTA 가 탭바에 가리지 않게).

### 종목 리스트 (movers·검색·관심종목)
```
[툴바: 세그먼트(지표) · 세그먼트(시장) · 우측 정렬]  높이 36, 패딩 20/24
[카드 radius-dense 16, 패딩 0]
  [헤더 44: 순위 56 | 종목 1fr | 지표 .55fr | 가격 .45fr | 등락 .4fr]  sunken, micro
  [행 68] ...
모바일: 헤더 숨김, 행 78 → grid "rank identity price / rank metric change", 순위 32
```

### 종목 상세
```
[헤더 카드: 종목명 title-1 + 시장 태그 / 현재가 price-lg + 등락 change / 관심 ★ 버튼]
[세그먼트: 1D 1W 1M 3M 1Y]  [차트 카드 360~480]
[KPI 4열: 시총·PER·PBR·배당]  (모바일 2열)
[탭: 개요 · 수급 · 재무 · 뉴스]
[콘텐츠 2열 (2fr 1fr) — 우측 sticky 패널 340, top sticky-offset]
```

### 기술 차트 워크스페이스
컨테이너 `2xl`. `[캔버스 1fr | 분석 패널 340]`, gap 16. 1023 이하 1열, 패널 static. 차트 480 / 모바일 360, 거래량 94 / 82.

### 대시보드(홈)
`[요약 카드 display 숫자] [KPI 4열] [2열 (2fr 1fr): 차트 카드 / 리스트 카드] [전폭 표 카드]`. 모바일 전부 1열, KPI 2열.

### 폼(모의투자 주문·설정)
컨테이너 `sm`. 라벨 위, 필드 사이 `space.4`, 섹션 사이 `space.10`. 금액 입력은 `input.amount-typography`(28/800) + 키패드 프리셋 칩(+1만·+10만·최대). 제출은 하단 고정 CTA `control.lg` 전폭(모바일) / 우측 정렬(데스크톱).

## 5. 정렬
- 텍스트 좌측. 숫자 열 우측 + tabular. 가운데 정렬은 빈 상태·확인 시트만.
- 종목 행: 왼쪽 식별(로고·이름), 오른쪽 숫자(가격·등락). 가운데 열은 보조 지표.
- 버튼 그룹: 데스크톱 우측 정렬, 주 버튼 오른쪽. 모바일 세로 쌓기, 주 버튼 위.
- 헤더 액션 아이콘 버튼 사이 `space.2`, 각 44.
