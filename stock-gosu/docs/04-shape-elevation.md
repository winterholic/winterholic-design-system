# 04 · 모양·깊이 (stock-gosu)

금융 앱은 base 보다 한 단계 더 둥글고, 그림자는 더 옅다. "둥근 모서리는 안전한 인상, 약한 그림자는 정보 레이어"(기존 FDS).

## 1. radius
| 토큰 | px | 언제 |
|---|---|---|
| `none` | 0 | 표 셀, 전폭 배너, 화면 끝에 붙은 이미지 |
| `xs` | 4 | 체크박스, 인라인 코드, 미니 태그, 스켈레톤 글자 |
| `sm` | 6 | 세그먼트 활성 항목, 툴팁 |
| `md` | 8 | sm 버튼, 칩, 드롭다운 항목 hover, 카드 안 작은 상자 |
| `lg` | 12 | **버튼(md)·인풋·드롭다운·차트 툴팁·검색창**. 기존 radius-12 |
| `xl` | 16 | 밀도 높은 카드(표·리스트 컨테이너), 검색 결과 패널, lg 버튼 |
| `2xl` | 20 | **카드 기본·모달·바텀시트**. 기존 .card |
| `3xl` | 24 | 온보딩 히어로 카드 |
| `full` | | 배지·시장 태그·아바타·토글·필 칩 |

규칙
- 카드 20 > 카드 안 상자 8~12 > 그 안 태그 4/full. 자식이 부모보다 둥글면 모서리가 뜬다.
- 표·리스트를 감싸는 카드는 `xl`(16). 안에 행이 빽빽하니 20 은 과하다.
- 버튼 필(full)은 필터 칩·"관심 추가" 같은 칩형에서만. 폼 버튼은 12.

## 2. 테두리
`hairline` 1 (기본) · `medium` 1.5 (아웃라인 버튼, 기존 btn-outline) · `focus` 2 · `accent` 3 (탭 인디케이터, 등락 좌측 바).

- 밀도 높은 화면(표·리스트) → 테두리 `border.default`, 그림자 없음.
- 카드 갤러리·홈 → `shadow.sm` + `border.default`. stock-gosu 카드는 둘 다 쓴다(기존 .card). 다크에서는 테두리가 주 신호.
- 등락 좌측 바: 알림·신호 카드 왼쪽 3px `finance.<d>.solid`. 카드 전체를 칠하지 않는다.

## 3. 그림자
| 토큰 | 기존 이름 | 언제 |
|---|---|---|
| `xs` | | 세그먼트 활성 항목, 토글 손잡이 |
| `sm` | shadow-1 | 카드 기본 |
| `md` | shadow-2 | 카드 hover(card-tap), 드롭다운, 차트 툴팁 |
| `lg` | shadow-3 | 토스트, 바텀시트, 검색 결과 패널 |
| `xl` | shadow-4 | 모달 |
| `inner` | | 눌린 세그먼트, sunken 인풋 |
| `sticky` | | 스크롤 시 sticky 헤더·하단 탭바 |

- hover 는 `sm → md` + `translateY(-2px)`(`card.hover-lift`). 클릭 가능한 카드(`card-tap`)만.
- 한 화면에 그림자 단계 두 개까지.
- 다크에서는 `shadow-dark.*` 로 자동 교체되고 alpha 가 올라간다. 그래도 테두리를 같이 둔다.

## 4. 그라데이션
금융 화면은 그라데이션을 거의 쓰지 않는다. 다섯 곳뿐.

| 토큰 | 언제 | 각도 |
|---|---|---|
| `brand` | 온보딩 헤더, 프로모션 카드, 앱 스토어 이미지. 위 글자 white | 135 |
| `sky` | 홈 상단 요약 카드 배경(거의 안 보임). 위 글자 그대로 | 180 |
| `sparkline-up` / `sparkline-down` | 스파크라인·영역 차트 채움 | 180 |
| `scrim-bottom` | 뉴스 썸네일 위 제목 | 180 |
| `fade-right` | 가로 스크롤 칩·탭 오른쪽 끝 "더 있음" 힌트 | 90 |

버튼·배지·KPI 에 그라데이션 금지. 다크에서 `sky`·`fade-right` 는 원시 참조라 밝게 남는다 → 다크에서는 `surface.default` 단색으로 대체(09).

## 5. 불투명도·블러
| 토큰 | 값 | 언제 |
|---|---|---|
| `opacity.disabled` | 0.4 | 비활성 |
| `opacity.stale` | 0.6 | 장 마감·지연 시세 등 **낡은 데이터** 표시. 숫자 옆 "15:30 기준" 문구 동반 |
| `opacity.chart-inactive-series` | 0.25 | 범례 hover 시 다른 시리즈 |
| `opacity.skeleton` | 0.6 | 스켈레톤 최저점 |
| `blur.md` | 12 | 글래스 상단 탐색·하단 탭바 `backdrop-filter` |

## 6. 하지 말 것 → 대신
| ❌ | ✅ |
|---|---|
| 표 카드 radius 20 | `xl` 16 |
| 정지 카드에 `shadow.lg` | `shadow.sm` |
| 등락 카드 배경 전체 빨강 | 좌측 3px 바 + 배지 |
| KPI 타일 그라데이션 | 단색 `surface.default`, 숫자로 말한다 |
| `box-shadow: 0 4px 16px rgba(0,27,55,.08)` 직접 | `var(--sg-shadow-md)` |
| 다크에서 라이트 그라데이션 그대로 | `surface.default` 단색 |
