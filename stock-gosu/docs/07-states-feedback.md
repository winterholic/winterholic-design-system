# 07 · 상태와 피드백 (stock-gosu)

투자 화면은 데이터가 늘 있는 게 아니다. 장 마감·지연·집계 전·오류를 화면 상태로 설계한다. 모든 화면은 아래를 전부 갖는다.

| 상태 | 언제 | 표시 |
|---|---|---|
| 첫 로딩 | 진입 | 스켈레톤(같은 레이아웃) |
| 재조회 | 기간·지표 전환 | 기존 내용 유지 + 상단 무한 progress 2px, 또는 `opacity.stale` |
| 실시간 갱신 | 틱 | 셀 플래시 600ms, 갱신 시각 문구 |
| 장 마감·휴장 | 15:30 이후·주말 | neutral 배너 "장 마감 · 15:30 종가 기준". 시세 `opacity.stale` 아님(종가는 확정값) |
| 지연 시세 | 수집 지연 | 시세 `opacity.stale` + 배너 "시세가 5분 지연되고 있어요" |
| 집계 전 | 지표 미산출 | 값 `—` + 툴팁 "집계 전". 0 이 아니다 |
| 빈 상태 | 0건 | §2 |
| 부분 실패 | 일부 종목 실패 | warning 배너 + 실패 항목 행에 `—` + 다시 시도 |
| 오류 | 요청 실패 | §3 |
| 오프라인 | | neutral 배너 "오프라인이에요. 연결되면 자동으로 다시 불러와요". 마지막 데이터 유지 + 시각 |
| 권한·로그인 필요 | 관심종목·모의투자 | 빈 상태 형태 + "로그인하면 관심종목을 저장할 수 있어요" |
| 성공 | 저장·주문 | §5 |

## 1. 로딩
- 300ms 규칙. 300ms 안에 오면 아무것도 안 보인다.
- 첫 로딩은 스켈레톤(종목 행 5개·KPI 4개·차트 영역 사각형). 재조회는 유지 + progress.
- 차트 로딩: 차트 영역 높이 그대로 스켈레톤 사각형. 축·격자만 먼저 그리고 선을 나중에 그리지 않는다(빈 축이 "데이터 0" 으로 읽힌다).
- 버튼 클릭(주문·저장): 그 버튼만 loading. 화면 전체 스피너 금지.
- 10초 초과: "시간이 걸리고 있어요" + 취소.

## 2. 빈 상태 (기존 `.empty`)
```
아이콘 48 (배경 원 80 brand-subtle, text.brand)   ← 위 space.12
title-3 제목                                       ← 아래 space.2
body-3 secondary 설명 1~2문장                       ← 아래 space.6
primary md 주 액션 1개 (+ 링크 1개)
```
| 상황 | 제목 | 설명 | 액션 |
|---|---|---|---|
| 관심종목 없음 | "관심종목이 아직 없어요" | "종목 상세에서 ★ 을 누르면 여기에 모여요" | "종목 찾기" |
| 보유 종목 없음(모의투자) | "아직 보유한 종목이 없어요" | "모의투자로 첫 매수를 해 보세요" | "종목 검색" |
| 검색 결과 없음 | "‘{검색어}’ 종목이 없어요" | "종목명·코드·티커로 검색해 보세요" | 없음 |
| 스크리너 조건 결과 없음 | "조건에 맞는 종목이 없어요" | "조건을 하나 풀어 보세요" | "조건 초기화" |
| 신호 없음 | "오늘은 신호가 없어요" | "장 마감 후 다시 집계돼요" | 없음 |
| 뉴스 없음 | "최근 뉴스가 없어요" | | |
| 로그인 필요 | "로그인하면 관심종목을 저장할 수 있어요" | | "로그인" |

카드·표 안 빈 상태 최소 높이 240. 일러스트 없이 아이콘으로 충분.

## 3. 오류
| 수준 | 표시 | 예 |
|---|---|---|
| 필드 | 테두리 `border.danger` + body-3 `text.danger` + 아이콘 | "수량은 1주 이상이어야 해요" |
| 동작 | 토스트(오류 6초) + "다시 시도" | "관심종목에 추가하지 못했어요 · 다시 시도" |
| 섹션(위젯) | 그 카드만: 아이콘 + 문구 + outline sm "다시 시도". 나머지 화면 유지 | 수급 카드만 실패 |
| 페이지 | 빈 상태 형태 + 오류 ID `micro` `text.tertiary` + "다시 시도" / "홈으로" | 500 |
| 데이터 소스 | 상단 배너 warning "일부 데이터를 불러오지 못했어요 (수급) · 다시 시도" | 수집기 실패 |

문구 공식 **[무엇이] + [왜] + [어떻게]**: "주문에 실패했어요. 주문 가능 금액이 부족해요. 1,284,500원 이하로 입력해 주세요."
- 사용자 탓 금지, 시스템 코드는 작게 뒤에.
- **오류 배너·토스트에는 아이콘 + 제목 필수.** 빨강이 상승과 겹치기 때문이다.

## 4. 확인 (되돌릴 수 없는 것만)
| 행동 | 확인 | 버튼 |
|---|---|---|
| 모의투자 매수·매도 | 시트: "삼성전자 10주 매수할까요?" + "724,000원 · 주문 가능 1,284,500원" | "매수" primary / "매도" danger |
| 전량 청산·계좌 초기화 | 시트 + 이름 입력 | "초기화" danger |
| 관심종목 삭제 | 확인 없음. 토스트 "삭제됨 · 되돌리기" 6초 | |
| 스크리너 조건 초기화 | 확인 없음. 되돌리기 | |
| 탈퇴 | 시트 + "탈퇴" 입력 | "탈퇴" danger |

파괴 동작이면 첫 포커스는 취소에.

## 5. 성공
| 행동 | 피드백 |
|---|---|
| 관심 추가 | ★ 채움 + 토스트 "관심종목에 추가했어요" 3초 |
| 모의 주문 | 시트 닫힘 → 성공 시트 "삼성전자 10주를 매수했어요 · 체결가 72,400원" + "보유 종목 보기" |
| 설정 저장 | 토스트 "저장됨" |
| 알림 조건 저장 | 토스트 "‘삼성전자 75,000원 돌파’ 알림을 켰어요" |

## 6. 비활성 vs 숨김
- 장 마감에 주문 버튼: **비활성 + "장 시작 후 주문할 수 있어요 (09:00)"**. 숨기지 않는다.
- 로그인 안 한 사용자의 관심 ★: 활성 + 누르면 로그인 시트. 비활성 아님.
- 권한 없는 관리자 메뉴: 숨김.

## 7. UX 문구 (기존 FDS 보이스 유지 + 금융 규제 관점)
- 해요체. 능동·현재형: "저장했어요"(O) "저장이 완료되었습니다"(X).
- 버튼은 동작: "매수" "매도" "관심 추가" "조건 저장". "확인/제출/OK" 금지.
- 같은 흐름에서 같은 동사: 버튼 "매수" → 토스트 "매수했어요".
- **단정 금지**: "확실한 수익" "무조건" "추천 종목" "지금 사세요" 금지. stock-gosu 는 정보·분석 서비스다. 신호는 "골든크로스 발생" 처럼 **사실**로, 판단은 사용자에게. 배지 문구도 "매수 신호" 대신 "상승 신호 감지".
- 면책 문구는 화면 하단 `micro` `text.tertiary` 한 줄: "투자 판단의 책임은 본인에게 있어요."
- 사과 남발 금지. 오류는 해결을 안내.
- 숫자·날짜·시간 표기는 02 §6.

| 이렇게 (O) | 이렇게 말고 (X) |
|---|---|
| 관심종목 | 즐겨찾기, 워치리스트 |
| 보유 종목 | 포지션 |
| 주문 가능 금액 | 가용 잔고, 예수금(상세 화면에서만) |
| 등락률 | 변동률, chg% |
| 거래대금 | 거래금액 |
| 다시 시도 | 재시도, 리트라이 |
| 불러오고 있어요 | 로딩 중, 잠시만요 |
| 장 마감 | 시장 종료 |
