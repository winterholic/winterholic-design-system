# 08 · 접근성 (stock-gosu)

목표 WCAG 2.2 AA. base 08 의 규칙에 금융 화면 특유의 것을 더했다.

## 1. 대비 (빌드가 106쌍 검사)
| 대상 | 기준 | 시스템에서 |
|---|---|---|
| 흰 카드 위 글자 | 4.5 | `text.*`, `finance.*.text`, `status.*.text` 전부 통과 |
| 캔버스(#F2F4F6) 위 글자 | 4.5 | **`primary`·`secondary` 만 통과.** 나머지는 카드 안에서 |
| 등락 큰 숫자(20px bold 이상)·배지·차트 | 3 | `finance.*.solid` |
| 배지 안 글자 | 4.5 | `finance.*.on-bg` (700) |
| 아이콘·체크박스 테두리·포커스 링 | 3 | `status.*.icon`, `input-strict`, `focus-ring` |
| primary 버튼 | 3 (라벨 15/600) | `action.primary` 3.71. AA 엄격은 `primary-strict` 4.66 |

주의: `action.primary`(#3182F6 + 흰 글자) 는 3.71 로 텍스트 AA 미달이다. 기존 제품과 브랜드 인상을 유지하려 남겼고, 계정·결제·공공 기준 화면은 `primary-strict` 를 쓴다. 이 결정은 `13 §7` 에 기록.

## 2. 색 이외의 신호 (금융에서 가장 중요)
- 등락: 색 + 부호(`+`/`−`) 필수. 배지·큰 숫자엔 화살표 추가. **색맹 사용자는 빨강·파랑을 구분 못 할 수 있다** — 부호가 없으면 방향을 모른다.
- 캔들: 상승·하락 색 + 속 채움 차이(상승 채움, 하락 빈 캔들) 옵션 제공. 최소한 툴팁에 "시가→종가".
- 차트 시리즈: 범례 + 선 끝 라벨. 색만으로 식별시키지 않는다(기존 chartTheme 주석 규칙 유지).
- 히트맵: 셀 안에 숫자 표기. 색만 있는 히트맵 금지.
- 상태 배지: 아이콘 또는 문구. 도트만 금지.

## 3. 포커스·키보드
- `typography.css` 가 `:focus-visible` 링 전역. `outline: none` 금지.
- 종목 행(링크)·표 행: Tab 으로 도달, Enter 로 이동. 행 안 ★ 버튼은 별도 탭 스톱.
- 검색 결과: ↑↓ 이동, Enter 선택, Esc 닫기, `role="listbox"` + `aria-activedescendant`.
- 세그먼트·탭: ←→ 이동, `role="tablist"`.
- 차트: 키보드로 데이터 포인트 탐색이 어려우면 **표 대안**(§5) 제공.
- 바텀시트·모달: 포커스 트랩, Esc, 닫히면 트리거로 복귀.

## 4. 터치
- 44×44 최소. 종목 행 68, 탭바 56, 버튼 44 가 이미 만족. 표 xs 버튼 28 은 셀 패딩으로 44 확보.
- 인접 타깃 8px 이상. 하단 탭 5개는 375 에서 각 75px.
- 스와이프 제스처(관심 삭제·시트 닫기)는 항상 버튼 대안이 있다.

## 5. 시맨틱·스크린리더
| 요소 | 규칙 |
|---|---|
| 가격·등락 | `<span aria-label="상승 1.68퍼센트">▲ 1.68%</span>`. 화살표 문자만 두면 "검은 위쪽 삼각형" 으로 읽힌다 |
| 실시간 갱신 영역 | `aria-live="polite"` 는 **쓰지 않는다**(틱마다 읽으면 못 쓴다). 갱신 시각만 `aria-live` |
| 차트 | `<figure>` + `<figcaption>` 한 문장 요약("삼성전자 1개월 주가, 5.2% 상승") + 시각적으로 숨긴 `<table>` 데이터 |
| 표 | `<th scope>`, `<caption>`, 정렬 열 `aria-sort` |
| 하단 탭바 | `<nav aria-label="주 메뉴">`, 활성 `aria-current="page"` |
| 세그먼트 | `role="tablist"` / `tab` / `aria-selected` |
| 시장 태그 | 장식이 아니라 정보 → 텍스트 그대로 |
| 종목 로고 | `alt=""`(이름이 옆에 있음) |
| 숫자 축약 | "412조 5,000억" 은 그대로 읽히니 OK. "1.2M" 같은 영문 축약 금지 |
| 토스트 | `role="status"`(성공) / `role="alert"`(오류) |

## 6. 모션·시간
- reduced-motion: 토큰이 처리. 플래시 0ms → 부호가 정보를 대신한다.
- 자동 갱신 화면(순위)은 일시정지 버튼.
- 토스트 오류 6초, 액션 있으면 닫힘 없음.

## 7. 확대·반응형
- 200% 확대 가로 스크롤 없음(표는 컨테이너 스크롤 허용).
- 375px 콘텐츠 손실 없음.
- 인풋 모바일 16px(iOS 확대 방지).
- `user-scalable=no` 금지.

- [ ] Tab 만으로 종목 행·검색·세그먼트·시트 조작
- [ ] 스크린리더로 가격·등락이 방향 포함해 읽힘
- [ ] 차트마다 요약 문장 + 표 대안
- [ ] 200% 확대, 375px 확인
