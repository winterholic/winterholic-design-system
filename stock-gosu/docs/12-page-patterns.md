# 12 · 페이지 패턴 (stock-gosu)

`front/src/App.tsx` 의 실제 화면 영역(홈·종목·시장·섹터·연구·자산·정보·계정)을 유형별로 골격화했다. 새 화면은 여기서 가장 가까운 것을 복사한다.

## 1. 홈 (요약 대시보드)
```
컨테이너 xl, 상단 space.6
  [시장 상태 배너 neutral: "장 마감 · 15:30 종가 기준"]  (장중엔 없음)
  [요약 카드 2xl 패딩 24, 배경 gradient.sky(다크: default)]
    caption "내 자산"  / display 12,840,000원 / change ▲ 240,000 (+1.9%)  / micro "모의투자"
  [지수 KPI 3열: KOSPI · KOSDAQ · USD/KRW]  price-md + change + 스파크라인 40
  [2열 (2fr 1fr)]
    카드 "오늘의 시장" — 세그먼트(등락률·거래대금) + stock-row compact 5개 + "전체 보기 →"
    카드 "관심종목" — compact 행 5개 / 빈 상태
  [카드 "신호" — 신호 배지 + 종목 행 3개]  (신호는 사실 문구, 07 §7)
  [뉴스 카드 3열 (모바일 가로 스크롤)]
모바일: 전부 1열, KPI 2열+1, 하단 탭바
```

## 2. 종목 목록 (movers · 스크리너 · 섹터 종목)
```
page-header: title-1 + body-3 설명 + 우측 outline sm "필터"
툴바(카드, 패딩 20/24): 세그먼트(지표) · 세그먼트(시장) · 우측 정렬 드롭다운  높이 36
  스크리너: 필터 칩 가로 스크롤 + "조건 초기화" ghost sm
카드 radius-dense 16, 패딩 0
  표 헤더 44 (모바일 숨김) → stock-row 68 (모바일 78) × N
  하단: "상위 100개까지 표시" micro 안내 또는 페이지네이션 sm
빈: 07 §2 / 로딩: 행 스켈레톤 8
```
- 순위 열은 `rank-typography` `text.tertiary`, 1·2·3 위만 `text.primary`.
- 정렬 기본값: 등락률 내림차순. 사용자 정렬은 URL 에.

## 3. 종목 상세
```
컨테이너 lg
  breadcrumb(시장 › 종목)  (아래 space.2)
  헤더 카드: 로고 40 + [title-1 삼성전자 + [KOSPI] / micro 005930 · 반도체]  우측 ★ 관심(outline sm) · 공유(ghost sm 아이콘)
             price-lg 72,400 + change ▲ 1,200 (+1.68%)  + micro "15:30 기준"
  세그먼트 기간(1D 1W 1M 3M 1Y 3Y) + 차트 카드 360 (선/캔들 토글 outline xs)
  KPI 4열: 시가총액 · PER · PBR · 배당수익률  (모바일 2열)
  탭: 개요 · 차트 · 수급 · 재무 · 뉴스 · 공시  (URL 연동)
  2열 (2fr 1fr): 본문 섹션 카드들 / 우측 sticky 패널(top sticky-offset): 관련 종목·같은 섹터
모바일: 헤더 카드 → 세그먼트 → 차트 240 → KPI 2열 → 탭(가로 스크롤) → 1열, 하단 고정 "모의 매수" lg primary (로그인 시)
```

## 4. 기술 차트 워크스페이스
```
컨테이너 2xl
  툴바 카드: [종목 검색 48 + 시장 세그먼트] [현재 종목 title-3 + price-md] [기간 세그먼트 44]
  요약 KPI 3열(116): 추세 · RSI · 거래량 배수
  [캔버스 1fr | 분석 패널 340 sticky]
    캔버스 카드 패딩 24: 헤더(종목 + 가격) + 캔들 480 + 거래량 94
    패널: 헤더 + 프리셋 탭 2열(58) + 오버레이 카드 리스트(58, 스위치) 스크롤
  안내 상자 card-flat body-2: 지표 설명
1023 이하: 1열, 패널 static, 오버레이 2열 / 767 이하: 차트 360, 프리셋 가로 스크롤 138
```

## 5. 시장 (국면·심리·수급)
```
page-header
  KPI 4열: 국면 배지(status.info) · 심리 지수 price-md · 외국인 순매수 change · 기관 순매수 change
  2열: 차트 카드(수급 누적 막대 240, 시리즈 외국인 1·기관 3·개인 2) / 설명 카드 body-2
  전폭: 섹터 히트맵(트리맵, chart.heat, 셀 종목명 + 등락률)
```

## 6. 자산 (포트폴리오 · 관심종목 · 모의투자)
```
요약 카드: display 평가금액 / change 평가손익 / KPI 3열(투자원금·수익률·현금)
비중: 가로 누적 막대 1개(series 색) + 범례
보유 종목 표: 종목 · 수량 · 평단 · 현재가(price-cell) · 평가손익(change) · 비중(progress 4)  행 48, 첫 열 sticky
관심종목: stock-row compact + 스와이프 삭제(버튼 대안 ⋯ 메뉴)
모의 주문 시트: 종목 헤더 → 매수/매도 세그먼트 → 수량 스텝퍼 44 → 금액 amount 입력 + 프리셋 칩 → 요약(주문금액·수수료·주문 가능) → CTA lg "매수"
```

## 7. 뉴스 · 공시 · 캘린더
```
필터 칩(전체·관심종목·시장) + 세그먼트(최신·중요)
뉴스 카드: 썸네일 16:9 + title-4 2줄 clamp + micro 출처 · 3분 전 + 관련 종목 태그(market-tag 스타일)
공시: 표 48 — 시각 · 종목 · 제목(링크 + external-link 12) · 유형 배지
캘린더: 주간 헤더 + 이벤트 행(실적·배당락·FOMC), 오늘 열 selected-bg
```

## 8. 계정 · 설정
```
컨테이너 lg(1024)
  title-1 "설정"  (아래 space.6)
  좌 세로 탭 200 (모바일: 상단 세그먼트 가로 스크롤) · 우 콘텐츠 (gap space.8)
    섹션 카드 lg 패딩 24, 사이 space.6
      title-3 + body-3 설명  (아래 space.5)
      설정 행 56: 좌 label-md + caption 설명 / 우 컨트롤, 구분선 border.subtle
```
| 섹션 | 행 | 컨트롤 |
|---|---|---|
| 화면 | 테마 | 세그먼트 시스템/라이트/다크 → `data-theme` + localStorage |
| | 등락 색상 | 세그먼트 한국식(빨강↑)/미국식(초록↑) → `data-market` |
| | 표 밀도 | 세그먼트 보통/촘촘 → 표 행 48/40 |
| | 시작 화면 | Select sm 홈/시장/자산 |
| 알림 | 가격 알림·신호 알림·뉴스 | Switch(즉시 반영) |
| 시세 | 자동 갱신 주기 | 세그먼트 5초/30초/수동 |
| 계정 | 이메일·비밀번호·2FA | 행 클릭 → 모달 md, `primary-strict` |
| 데이터 | 관심종목 내보내기 | outline sm "CSV 내보내기" |
| 위험 구역 | 모의투자 초기화 · 탈퇴 | 카드 테두리 `status.danger.border`, `danger` outline → 확인 시트 + 이름 입력 |

즉시 반영 행은 Switch·세그먼트, 저장 필요한 행은 섹션 하단 "저장" primary sm(변경 시에만 활성).

## 9. 로그인
컨테이너 sm, 로고 32, title-2, 필드 lg(52) × 2, primary-strict lg 전폭(계정 화면은 엄격 대비), 소셜 outline lg, 하단 caption 링크. 오류는 폼 상단 danger 배너(어느 쪽이 틀렸는지 노출 금지).

## 10. 온보딩 (첫 진입)
컨테이너 sm. 헤더 카드 `gradient.brand`(다크: `surface.brand`) 파랑새 심볼 80 + display-lg 흰 글자 → 3단계(관심 시장 선택 칩 · 관심 종목 검색 3개 · 알림 허용), 프로그레스 4px 상단, 하단 lg "다음"/"시작하기", "건너뛰기" ghost. 단계 표시 caption "2 / 3".

## 11. 오류 페이지 (404 · 500 · 403 · 데이터 장애)
```
canvas, 세로 가운데, 컨테이너 sm
  아이콘 2xl(48) text.tertiary 또는 파랑새 심볼 80  (아래 space.4)
  title-2 "페이지를 찾을 수 없어요"  (아래 space.2)
  body-2 text.secondary 한 문장  (아래 space.8)
  primary md "홈으로" + ghost "이전 페이지"
  micro text.tertiary 오류 ID (500)  (위 space.8)
```
| 코드 | 제목 | 설명 | 액션 |
|---|---|---|---|
| 404 | "페이지를 찾을 수 없어요" | "주소가 바뀌었거나 삭제된 종목이에요" | 홈으로 · 종목 검색 |
| 403 | "볼 수 있는 권한이 없어요" | "관리자 화면이에요" | 홈으로 |
| 500 | "문제가 생겼어요" | "잠시 후 다시 시도해 주세요 · 오류 ID abc123" | 다시 시도 · 홈으로 |
| 데이터 수집 장애 | "지금 시세를 불러올 수 없어요" | "마지막 갱신 15:30 기준으로 보여드려요" | 캐시된 화면 유지 + 상단 warning 배너. 전체 오류 페이지로 보내지 않는다 |
| 점검 | "점검 중이에요 (02:00~03:00)" | | 없음 |

## 12. 알림 센터
헤더 bell → 드롭다운(데스크톱 400) / 페이지(모바일). 항목 68: [아이콘 원 32 `status.<s>.bg` + icon] [title-4 종목 + 본문 body-3] [micro 시각]. 읽지 않음 `selected-bg`. 상단 세그먼트 전체/가격/신호/뉴스, 우측 "모두 읽음" ghost sm. 빈 상태 "알림이 없어요". 알림 설정 링크 하단.

## 13. 검색 결과 페이지 (헤더 검색 Enter)
title-1 "‘삼성’ 검색 결과" + micro "12건". 세그먼트 전체/종목/뉴스/공시. 종목: stock-row compact 리스트. 뉴스: 카드 3열. 없음: 07 §2 + 최근 검색.

## 14. 종목 비교
컨테이너 xl. 상단 종목 칩 최대 4개(칩 + X, "종목 추가" outline sm). 정규화 선 차트 360(series 1~4). 아래 비교 표: 행 = 지표(시총·PER·PBR·배당·1M·3M·1Y), 열 = 종목. 첫 열 sticky 160. 셀 numeric, 등락 change. 최고값 `text.brand` 굵게. 모바일: 표 가로 스크롤.

## 15. 관리자 (수집기·잡 상태)
사이드바 240 + 콘텐츠. 잡 표: 이름·상태 배지(성공 success/실패 danger/실행 중 info + 스피너)·마지막 실행·소요·액션(다시 실행 outline xs). 로그 뷰어 `surface.sunken-strong` 코드 블록. 진행률 progress 8. **등락색을 상태에 쓰지 않는다**(15 §2 #27).
