# 16 · 상황 사전 — "이럴 땐 이렇게" (stock-gosu)

00 결정표가 "무엇을 쓸까"라면, 이 문서는 "이 상황이 왔는데 어떻게 하지"다. 개발하다 막히는 지점을 상황별로 미리 답했다. 없는 상황은 가장 비슷한 항목을 따르고 §끝 절차로 추가한다.

## A. 글자·숫자

| 상황 | 이렇게 |
|---|---|
| 종목명이 너무 길다("삼성전자우선주2020(신형)") | 1줄 말줄임 + `title` 툴팁. 표 열 폭은 줄이지 않는다. 모바일은 2줄 clamp 허용 |
| 가격이 자릿수가 커서 셀을 넘친다(1,234,567,890) | `nowrap` 유지, 열 폭을 최대 자릿수 기준으로 고정. 요약 화면은 만/억 축약(02 §6). 절대 줄바꿈하지 않는다 |
| 등락률 0.00% | `finance.flat.text`, 부호·화살표 없음 |
| 등락률이 ±100% 넘음(신규 상장) | 그대로 표기 "+312.40%". 색·부호 규칙 동일 |
| 값이 아직 없음(집계 전) | `—`(em dash) + 툴팁 "집계 전". `0`·`-`·빈칸 금지 |
| 값이 진짜 0 | "0" / "0원". `—` 아님 |
| 데이터가 지연·마감됨 | 숫자 `opacity.stale` 0.6 + 옆 `micro` "15:30 종가" |
| 음수 표기 | `−`(U+2212). 하이픈 금지 |
| 달러 종목 | `$142.80`, 소수 둘째 자리. 원화 환산은 `caption` 아래 |
| 큰 금액 요약 vs 상세 | 요약 "1,284만원", 상세 "12,840,000원". 툴팁으로 전체값 |
| 거래량 | "1,204만주". K/M 금지 |
| 퍼센트 포인트 변화(수익률 차이) | "+0.3%p" |
| 날짜·시간 | `2026.09.19` `15:30`. 상대 시간은 7일까지 |
| 영문·한글 혼용 종목명 | Pretendard 가 둘 다 처리. 별도 서체 없음 |
| 제목이 두 줄로 접힌다 | 허용(title 행간 1.35). 세 줄이면 문구를 줄인다 |
| 표 헤더가 길다 | 2줄 허용, 높이 44→56. 약어 대신 툴팁 |

## B. 등락·색

| 상황 | 이렇게 |
|---|---|
| 13px 등락률에 `#F04452` 를 쓰고 싶다 | 안 된다(3.71). `finance.up.text`(#E0263A). 20px bold 이상만 `solid` |
| 배지 안 등락 글자 | `finance.up.on-bg`(700) on `up.bg` |
| 캔버스(회색) 위에 캡션을 놓아야 한다 | `text.secondary` 로 올리거나 흰 카드 안으로. tertiary 는 캔버스에서 4.19 |
| 오류 메시지가 상승 빨강과 헷갈린다 | 오류는 아이콘(circle-x) + 제목 필수. 등락 옆에 오류 배지 두지 않는다 |
| 미국 종목 카드가 한국 종목 옆에 있다 | 카드마다 `data-market="us"`. 화면 전체가 아니라 컨테이너 단위로 |
| 사용자가 설정에서 미국식 전체 반전 | `<html data-market="us">` |
| 시리즈 색이 9개 필요 | 9번째부터 `chart.series.other`(회색) 로 접거나 차트를 나눈다 |
| 시리즈 비교 차트에 빨강·파랑 시리즈가 상승·하락처럼 읽힌다 | series.1(파랑)은 OK(브랜드), series.8(빨강)은 6개 이하로 제한. 방향 의미 차트는 6색 |
| 좋은 방향이 하락인 지표(오류율·부채비율) | 색은 값의 방향 그대로. 라벨에 "(낮을수록 좋음)" |
| 브랜드 파랑을 큰 면에 깔고 싶다 | `surface.brand`(blue.600) 온보딩·프로모션만. 앱 화면은 `brand-subtle` |
| 상태(성공/실패)를 표시하는데 등락색을 쓰고 싶다 | 금지. `status.success/danger`. 등락은 값의 방향에만 |
| 히트맵 셀 글자색 | up-3·up-2·down-2·down-3 는 white, 나머지 gray.900 |
| 다크에서 흰 글자 primary 버튼 | 토큰이 blue.400 + gray.950 으로 바꾼다. 흰 글자 강제 금지 |
| 캔들 속 채움/빈 캔들 | 기본 둘 다 채움. 설정에서 "하락 빈 캔들" 옵션 |

## C. 레이아웃·간격

| 상황 | 이렇게 |
|---|---|
| 툴바에 컨트롤이 6개 넘는다 | 우선순위 3개 + "필터" outline sm → 바텀시트/드로어. 한 줄 넘기지 않는다 |
| 세그먼트 항목이 8개 | 6개 초과면 드롭다운 또는 가로 스크롤 + `fade-right` |
| 표 열이 12개 | 5개 이상은 가로 스크롤 + 첫 열 sticky. 모바일은 4개 넘으면 stock-row |
| 카드 안에 카드가 필요해 보인다 | `surface.sunken` 구획(card-flat) 또는 `border.subtle` 구분선 |
| 카드 안 표 | 카드 패딩 0 + `radius-dense` 16, 표가 카드 끝까지 |
| 카드 안 차트 | 카드 패딩 20 유지, 차트 좌우 −8 로 살짝 넓힘(축 라벨 여유) |

| 모바일에서 KPI 4개 | 2열 × 2. 5개면 2·2·1 |
| 모바일 하단 CTA 와 탭바가 겹친다 | CTA 바를 탭바 위에, 본문 하단 패딩 = 탭바 56 + CTA 68 + 16 |

| 스크롤 앵커가 헤더 뒤로 숨는다 | `scroll-margin-top: 128px` |
| 페이지 좌우 여백이 375 에서 좁아 보인다 | 20 고정. 카드 패딩을 16 으로 줄인다(`card.padding-sm`) |
| 가로 스크롤 영역 끝을 알리고 싶다 | 우측 `fade-right` 32px + 스크롤바 숨김 |
| 한 화면에 primary 버튼이 두 개 필요 | 하나는 secondary. 예외: 매수(primary)+매도(danger) |
| 버튼 세 개 이상 나란히 | 주 1 + 보조 1 + 나머지 ⋯ 메뉴 |
| 빈 화면 높이 | 카드·표 안 240, 페이지 전체는 세로 가운데 |
| 두 헤더(상단 64 + 보조 48) 아래 첫 콘텐츠 | 위 24 |

## D. 컴포넌트 조합

| 상황 | 이렇게 |
|---|---|
| 종목 행에 관심 ★ + ⋯ 두 버튼 | 우측 끝 ★(28, 터치 44) 하나만. ⋯ 은 스와이프/롱프레스 또는 상세로 |
| 카드 전체 클릭 + 안에 버튼 | 둘 중 하나. 카드 클릭이면 안 버튼은 ★ 만 `stopPropagation` |
| 배지가 3개 이상 | 2개 + "+N". 배지 줄바꿈 금지 |
| 필터 칩 선택이 다중인지 단일인지 | 지표·시장 = 단일(세그먼트), 섹터·태그 = 다중(칩 + X) |
| 드롭다운 항목이 50개(종목·섹터) | 검색 인풋 상단 + 최대 높이 320 스크롤 |
| Select 에서 옵션 설명이 필요 | 항목 2줄(label-md + body-3 tertiary), 높이 52 |

| 시트 안 폼이 길다 | 본문 스크롤, 헤더·CTA 고정, 최대 90vh |
| 확인 다이얼로그에 요약이 필요(주문) | `surface.sunken` 상자 패딩 16, 라벨 좌·값 우 numeric |
| 툴팁이 터치에서 안 뜬다 | 터치는 탭 → 팝오버(닫기 X). ⓘ 아이콘 버튼으로 |

| 표 정렬 기본값 | 등락률↓(순위) / 시총↓(스크리너) / 시각↓(공시). URL 반영 |
| 페이지네이션 vs 무한 스크롤 | 표·스크리너 = 페이지네이션, 순위·뉴스 = 무한 + "더 보기" |
| 아이콘 버튼만 4개 나란히(헤더) | 최대 3 + ⋯. 각 44 |
