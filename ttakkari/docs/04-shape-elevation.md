# 04 · 모양·깊이 (Ttakkari)

## 1. radius: 손에 쥐는 앱

손가락으로 쓰는 앱이라 AIP(제도 용지)보다 한 단계 둥글다. 그래도 장난감처럼 둥글지는 않다. 카드 12, 다이얼로그 16 이 끝이다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `none` | 0 | 전폭 띠·표 셀 |
| `xs` | 2 | 인라인 코드·kbd·mark |
| `sm` | 4 | 체크박스·배지·툴팁·xs 버튼 |
| `md` | 8 | 버튼·인풋·셀렉트·메뉴 항목·글리프 타일. **기본** |
| `lg` | 12 | 카드·실행 카드·승인 카드·결과물 카드·코드 블록·로그·콜아웃·lg 버튼·메뉴 상자 |
| `xl` | 16 | 다이얼로그·바텀 시트 위 모서리·컴포저·사용자 말풍선·선택 바 |
| `2xl` | 20 | 로그인 패널·브랜드 히어로 |
| `full` | 9999 | 칩·스위치·상태 점·카운트 배지·아바타 위 점 |

- 큰 면일수록 큰 값. 자식은 부모보다 둥글지 않다(세그먼트 손잡이 = 트랙 radius − 패딩).
- 아바타·로고 타일은 비율(26%·22%)이다. 크기가 바뀌어도 같은 모양이다.
- 사용자 말풍선은 말한 쪽 아래 모서리만 4(`message.user-tail`)다. 누가 말했는지 모양으로도 말한다.

## 2. 선

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `border-width.hairline` | 1 | 모든 기본 테두리 |
| `border-width.strong` | 2 | 활성 탭 밑줄·탭바 위 표시·포커스 링·현재 히트 테두리 |
| `border-width.accent` | 3 | 실행 카드 상태 레일·승인 카드 바·콜아웃 바·짚은 코드 줄 |

레일·바는 `box-shadow: inset` 으로 그린다. 테두리로 그리면 radius 모서리에서 휜다.

## 3. 그림자: 떠 있는 것만

| 토큰 | 쓰는 곳 |
|---|---|
| `shadow.xs` | 세그먼트 활성 칸·스위치 손잡이 |
| `shadow.sm` | 클릭 가능한 카드 hover · 컴포저(스레드 위에 떠 있는 입력) · PDF 페이지 |
| `shadow.md` | 메뉴·툴팁·'새 메시지' 버튼 |
| `shadow.lg` | 다이얼로그·바텀 시트·드로어·토스트·선택 바 |

카드·실행 카드·결과물 카드·코드 블록·콜아웃에는 **그림자가 없다.** 그림자 색은 ink 계열이고 민트 글로우는 없다. 다크는 `shadow-dark.*` 로 자동 교체되며 고도의 주 신호는 면 밝기(`surface.raised`)다.

## 4. 배경 패턴: 둘뿐

| 패턴 | 토큰 | 쓰는 곳 |
|---|---|---|
| 체커 | `pattern.checker-size` 16 + `viewer.checker-a/b` | 투명 이미지 바탕(뷰어 Stage) |
| 점 격자 | `pattern.grid-size` 24 · `grid-dot` 1 + `border.default` | 로그인·빈 작업 공간(`.tk-dotgrid`) |

채팅·카드·폼 뒤에는 깔지 않는다.

## 5. 투명도

`opacity.disabled` 0.45 · `opacity.muted` 0.65(취소된 작업의 단계, hover 전 메시지 행동). 색 토큰 `action.disabled.*` 가 있으면 그쪽이 먼저다.

## 6. 하지 말 것

| ❌ | ✅ |
|---|---|
| 실행 카드에 상시 그림자 | 테두리 + 상태 레일 |
| 글래스모피즘 헤더 | 불투명 canvas + 하단선 |
| 민트 글로우·네온 | 없음 |
| 그라데이션 버튼 | 단색 |
