# 05 · 모션 (Ttakkari)

모션은 **상태가 바뀌었다는 설명**에만 쓴다. 장식 애니메이션·스크롤 연출·타이핑 효과는 없다. 유일한 반복 모션은 **실행 중 점의 맥박**이다. "에이전트가 지금 살아서 일하고 있다"는 정보 그 자체라서.

## 1. 토큰

| duration | 값 | 쓰는 곳 |
|---|---|---|
| `fast` | 120ms | hover 색·체크·스위치·탭 밑줄 |
| `normal` | 180ms | 메뉴·툴팁·단계 펼침·결과물 카드 도착·토스트·새 메시지 버튼 |
| `slow` | 260ms | 다이얼로그·바텀 시트·드로어·전체 화면 뷰어 |
| `live` | 1600ms | 실행 중 점 맥박 한 주기 |
| `tooltip-delay` | 400ms | 마우스 hover 후 툴팁. 키보드 포커스는 즉시, 터치는 띄우지 않음 |
| `feedback` | 1600ms | '복사됨'이 원래대로 |
| `toast` | 5000ms | 토스트 자동 닫힘(행동이 있으면 자동으로 닫지 않는다) |

| easing | 값 | 쓰는 곳 |
|---|---|---|
| `standard` | (0.2, 0, 0, 1) | 화면 안에서 바뀌는 것 |
| `enter` | (0, 0, 0, 1) | 들어오는 것 |
| `exit` | (0.4, 0, 1, 1) | 나가는 것(진입보다 짧게) |
| `linear` | | 스피너·맥박·진행 바 |

`distance.sm` 4px(메뉴·도착), `distance.md` 8px(토스트·다이얼로그).

## 2. 에이전트 신호의 움직임

| 상태 | 움직임 | 모션 축소 시 |
|---|---|---|
| 첫 글자 전(생각 중) | `.tk-thinking` 의 live 점 맥박 + 무엇을 하는지 한 줄 | 점 정지, 문구 그대로 |
| 스트리밍 중 | 본문 끝 민트 블록 `.tk-caret`. **깜빡이지 않는다** | 같음 |
| 실행 중 | 배지·단계·세션 목록의 live 점 맥박, 진행 막대 | 점 정지, 막대는 값만 |
| 결과물 도착 | 카드가 4px 아래에서 올라오며 나타남 + 민트 테두리 | 그냥 나타남 |
| 끝남 | 움직임 없음. 점이 체크 아이콘으로 바뀐다 | 같음 |

스트리밍 글자는 도착하는 대로 그린다. 글자를 일부러 늦게 흘리는 타이핑 효과를 만들지 않는다. 받은 것을 숨기는 것이다.

## 3. 규칙

1. `transition: all` 금지. 바뀌는 속성만(빌드 lint).
2. `ease-in-out` 같은 키워드 금지. easing 토큰만.
3. 메시지 글자는 움직이지 않는다. 움직이는 것은 크롬(시트·메뉴·탭 밑줄)과 에이전트 신호(점·커서)뿐.
4. 스크롤 리빌 없음. 새 메시지가 아래에서 튀어 오르지 않는다.
5. 스켈레톤은 정지(shimmer 없음).
6. 스레드는 바닥에 있을 때만 새 메시지를 따라 내려간다. 위로 올려 읽는 중이면 끌어내리지 않고 '새 메시지' 버튼을 띄운다(07 §5).

## 4. 모션 축소

`prefers-reduced-motion: reduce` 이면 `fast`·`normal`·`slow` 가 0ms(tokens.css), 맥박·무한 진행 바 애니메이션이 꺼진다(components.css). 스피너는 멈추지 않고 느려진다(진행 중이라는 정보는 남긴다). `feedback`·`toast`·`tooltip-delay` 는 움직임이 아니라 시간이라 그대로다. 부드러운 스크롤(`scrollTo smooth`)도 즉시 이동이 된다(tk.js).
