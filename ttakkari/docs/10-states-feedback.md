# 10 · 상태·피드백 (Ttakkari)

원격 앱이라 상태가 많다: 내 기기 ↔ 네트워크 ↔ Mac Studio ↔ 에이전트 ↔ 변환기. 어느 고리가 끊겼는지 사람이 알 수 있어야 한다.

## 1. 로딩

| 예상 시간 | 표시 |
|---|---|
| 300ms 미만 | 아무것도 표시하지 않는다(깜빡임 방지) |
| 300ms 이상 1초 미만 | 버튼이면 `aria-busy` 스피너, 영역이면 스켈레톤 |
| 1초 이상 | 스켈레톤 + 무엇을 하는지 한 줄(`.tk-status--agent` "파일을 찾는 중") |
| 진행을 알거나 5초 이상 | 단계·개수("12장 중 7장", "88 / 214") + 진행 막대 |
| 에이전트 작업 | 시간과 무관하게 Run card(08). 스피너만 두지 않는다 |

스켈레톤은 실제와 같은 개수·모양(목록: 글리프 + 두 줄 × 5행). 정지.

## 2. 빈 상태

`.tk-empty`: 무엇이 없는지(제목) + 왜·어떻게(한 줄) + 다음 행동 하나(또는 제안 칩). 빈 상태는 오류가 아니다. 빨강·경고색 금지.

| 상황 | 문구 | 행동 |
|---|---|---|
| 첫 실행·새 세션 | 무엇을 시킬까요? Mac Studio에서 할 일을 말로 지시하세요. | 제안 칩 2~3 |
| 작업 공간에 결과물 0 | 이 세션에는 아직 결과물이 없어요. | (없음, 채팅으로) |
| 보관함 검색 0 | 찾는 결과물이 없어요. 다른 단어로 찾거나 필터를 풀어 보세요. | 필터 모두 풀기 |
| 파일 찾기 0 | 허용된 위치에서 못 찾았어요. 위치를 넓히려면 설정 › 파일 접근. | 검색어 바꾸기 |
| 승인 대기 0 | (보이지 않는다. 빈 승인 목록을 만들지 않는다) | |

## 3. 오류

| 범위 | 컴포넌트 | 예 |
|---|---|---|
| 필드 | `.tk-error` + `aria-invalid` | "메일 주소 형식이 아니에요. @ 뒤를 채워 주세요." |
| 메시지 | `.tk-message__error` + 다시 시도 | "Mac Studio 와 연결이 끊겨 응답을 받지 못했어요." |
| 작업 | Run card `failed` + 단계 `step__detail` + 다시 할 행동 | "PPTX 저장에서 멈췄어요(image too large)" |
| 미리보기 | Viewer state `failed` + 원본 다운로드 | 09 §4 |
| 앱 전체 | Banner(`--danger`·`--warning`) | 재인증 필요 · 서버 오류 |
| 페이지 | 14 §7 오류 화면 | 404·500 |

문구 규칙: 무엇이 잘못됐는지 → 왜(알면) → 지금 할 수 있는 것. 사용자를 탓하지 않는다. 기계 이유는 모노로 덧붙인다(`convert: table nesting depth 6 > 4`). 색만으로 말하지 않는다(아이콘 + 단어).

## 4. 연결: 내 기기와 Mac Studio

| 상태 | 표시 | 할 수 있는 것 |
|---|---|---|
| 연결됨 | 헤더 메타 민트 점 "Mac Studio 연결됨" | 전부 |
| 다시 연결 중 | Banner `--warning` + 스피너 "실행 중인 작업은 그대로 진행돼요" · amber 점 | 읽기·초안 쓰기. 보내기는 대기열 |
| 오프라인(내 기기) | Banner `--neutral` + `wifi-off` · 컴포저 `data-offline` | 받아 둔 결과물 열기·초안 쓰기 |
| Mac Studio 꺼짐·응답 없음 | Banner `--danger` "Mac Studio 가 응답하지 않아요(마지막 응답 14:02)" | 읽기 |
| 인증 만료 | Banner `--danger` + 인증 버튼 → Dialog | 재인증 |

"연결이 끊겼다"와 "에이전트가 실패했다"를 섞지 않는다. 끊김은 회색·amber(아직 결과를 모른다), 실패는 빨강(결과가 실패다).

## 5. 성공·확인

- 짧은 확인은 그 자리에서: 복사 버튼이 1.6초 "복사됨", 보관함에 담으면 `.tk-status--success`.
- 다른 화면에 있을 때 끝난 작업은 Toast(행동 "열기") + 탭바 카운트 배지 + 세션 목록 상태.
- PWA 가 백그라운드일 때는 시스템 알림(권한을 받은 경우). 알림 문구는 토스트와 같다.
- 확인 상태는 `role="status"` 또는 `TK.announce()` 로 스크린 리더에도 알린다.
- 성공을 위해 다이얼로그를 띄우지 않는다.

## 6. 권한·정책 (Ttakkari 고유)

정책에 막히는 것은 오류가 아니라 **정상 동작한 보호**다. 빨강으로 겁주지 않고, 왜 막혔는지와 다음 길을 준다.

| 상황 | 표시 |
|---|---|
| 반출에 승인 필요 | 채팅 안 Approval card(amber). 결과물에는 `policy approval` 배지 |
| 민감·회사 자료(별도 정책) | `policy restricted`(자두, 잠금) + `.tk-policy-note` 로 범위 설명 |
| 반출 차단 | `policy blocked`(빨강, `ban`). 다운로드 버튼 `aria-disabled` + 이유 툴팁 + 본문 문장(툴팁만으로 말하지 않는다) |
| 허용된 위치 밖 | 검색 결과에 나오지 않는다. 결과 아래 안내 콜아웃 한 번 |
| 인증 정보 패턴 발견 | Checks `fail` + 반출 불가 문장 |
| 다운로드 링크 만료 | `.tk-status--danger` "링크가 만료됐어요" + 다시 받기(재인증이 필요하면 Dialog) |

## 7. 상태 문구 톤

- 해요체, 짧고 구체적으로. "문제가 발생했습니다" 대신 "Mac Studio 가 10초 동안 응답하지 않았어요".
- 동작 이름은 버튼과 같은 단어(보내기 → "보냈어요", 승인하고 보내기 → "승인했어요 · 보내는 중").
- 숫자로: "파일 3개", "결정 7건", "1분 42초".
- 시간은 상대 시간 7일까지("3일 전"), 그 뒤 `2026.10.09`.
