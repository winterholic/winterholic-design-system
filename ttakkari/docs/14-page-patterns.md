# 14 · 페이지 패턴 (Ttakkari)

화면마다 완성 템플릿이 `examples/` 에 있다. 새 화면은 가장 가까운 템플릿을 복사해서 시작한다. 특정 화면을 위해 시스템을 바꾸지 않는다. 필요하면 15 절차로 시스템에 먼저 넣는다.

| 화면 | 템플릿 | 요구사항 | 밀도 |
|---|---|---|---|
| 채팅 | `examples/chat.html` | §2.1·§3.1·§7 | 읽기 + 입력 |
| 작업 공간 | `examples/workspace.html` | §3.2·§4 | 목록 + 뷰어 |
| 보관함 | `examples/library.html` | §3.3·§5 | 목록 + 상세 |
| 파일 찾기 | `examples/files.html` | §2.3·§2.4·§6 | 검색 + 선택 + 내보내기 |
| 로그인·기기 연결 | `examples/auth.html` | §6(인증) | 한 열 |
| 전체 부품 | `examples/preview.html` | | |

## 1. 공통 셸

```html
<a class="tk-skip-link" href="#main">본문으로 건너뛰기</a>
<div class="tk-app">
  <aside class="tk-app__sidebar" aria-label="탐색"><div class="tk-app__brand">…</div><nav class="tk-sidebar">…</nav></aside>   <!-- lg 이상 -->
  <main class="tk-app__main" id="main" tabindex="-1">
    <div class="tk-screen">
      <header class="tk-header">…</header>
      <p class="tk-banner …">…</p>                      <!-- 앱 상태가 있을 때만 -->
      <div class="tk-screen__body">…</div>               <!-- 또는 .tk-thread / .tk-split -->
    </div>
  </main>
  <nav class="tk-tabbar" aria-label="영역">…</nav>      <!-- lg 미만 -->
</div>
```
- 영역은 넷: **채팅 · 작업 공간 · 보관함 · 파일**. 탭바·사이드바 내비가 같은 넷을 같은 순서로 가진다. 설정은 헤더 메뉴(또는 사이드바 아래).
- 헤더 제목은 그 화면의 h1 이다. 메타 줄은 연결 상태·대기 수.
- 푸터는 없다(앱).

## 2. 채팅

```
[헤더: 메뉴(모바일) · 세션 제목 / 연결·대기 · 작업 공간 열기(lg) · 테마 · 더보기]
[스레드(760 열): 날짜 · 사용자 말풍선 · 에이전트(글 → 실행 카드 → 승인 → 결과물 → 제안) · 새 메시지 버튼]
[컴포저 트레이: 문맥 칩 · 첨부 | 입력 | 보내기·멈추기 · 안내]
[탭바(모바일)]
```
- 세션 목록: 모바일은 헤더 메뉴 → 드로어, 데스크톱은 사이드바.
- 결과물 카드를 누르면 작업 공간으로 간다. 데스크톱(xl)은 채팅 화면 안에서 분할을 연다(`.tk-split` 의 primary = 스레드, secondary = 뷰어).
- 승인이 필요하면 헤더 메타·세션 행·탭바(채팅 칸 배지)가 함께 말한다. 다른 화면에 있으면 Toast "승인이 필요해요 · 보기".
- 빈 세션: 스레드 가운데 `.tk-empty`(에이전트 아바타 lg + "무엇을 시킬까요?" + 제안 칩).

## 3. 작업 공간

```
데스크톱: [사이드바 | 결과물 목록(세로 탭) ┃ 뷰어(툴바 · 찾기 · 안내 · 본문 · 후속 지시)]
모바일:   [헤더(뒤로·작업 공간) / 결과물 목록 / 탭바]  → 행을 누르면 전체 화면 뷰어(dialog)
```
- 목록은 현재 세션의 결과물. 그룹: "방금 · 이 세션" / "미리보기 없음"(실패·미지원·차단). 그룹 머리는 sticky.
- 목록 = `role="tablist" aria-orientation="vertical"`, 행 = `role="tab"`, 뷰어 = `role="tabpanel"`. 화살표로 결과물을 옮겨 다닌다.
- 모바일에서는 같은 뷰어를 `dialog.tk-viewer-dialog` 안에 렌더한다. 뒤로(툴바 왼쪽)·Esc·브라우저 뒤로 가기로 닫히고 고른 행으로 포커스가 돌아간다. 브라우저 뒤로 가기와 맞추려면 열 때 `history.pushState`(19 §5).
- 결과물 더보기: 모바일 Sheet, 데스크톱 Menu(원본 다운로드 · 보내기 · 보관함에 고정 · 이 결과물로 새 세션 · 삭제).
- 분할 손잡이 폭은 기억한다(`tk-split`).

## 4. 보관함

```
데스크톱: [사이드바 | 필터 바 + 날짜 그룹 목록 ┃ 상세(400)]
모바일:   [헤더 / 필터 바 / 목록 / 탭바] → 행을 누르면 상세 Sheet
```
- 필터 바: 검색(이름·세션·내용) + 형식 칩(전체·문서·PDF·표·이미지·발표·고정) + 정렬(md 이상) + 결과 수.
- 행: 글리프 · 이름 · 메타(세션 · 크기 · 시각 또는 보존) · 뒤(예외 정책 배지).
- 상세: 미리보기 썸네일 → 이름·배지 → 열기(primary) · 다운로드 · 더보기 → 탭 정보 | 기록.
- 검색 0건: 빈 상태 + "필터 모두 풀기".
- 7일 안에 정리될 결과물은 메타에 amber 보존 표시, 헤더 메타에 개수.

## 5. 파일 찾기

```
데스크톱: [사이드바(영역 + 허용된 위치 트리) | 검색 · 경로 · 결과 수 / 결과 목록(선택 체크) / 안내 / 선택 바]
모바일:   [헤더 / 검색 · 경로 / 결과 / 선택 바(탭바 위) / 탭바]
```
- 검색은 말로("지난달 계약서 PDF"). 결과 수 줄에 무엇으로 찾았는지("이름·내용·수정일(2026.09) 기준").
- 결과 행: 체크 · 글리프 · 이름(일치 형광펜) · 메타(경로 모노 · 크기 · 날짜) · 스니펫(일치 형광펜) · 정책 배지. 고를 수 없는 행은 `aria-disabled` + 이유 배지(회사 자료).
- 선택하면 선택 바: 다운로드 · 작업 공간에 담기 · 보내기(primary) · 해제.
- 보내기 → 내보내기 Sheet(`data-tk-modal`): 받는 사람 · 방법(메일 첨부 | 만료 링크) · 링크 만료 · 정책 판정(Checks) · 정책 안내 · "승인 요청하고 보내기".
- 결과 아래 안내 콜아웃 한 번: 허용된 위치 밖과 인증 정보는 결과에도 나오지 않는다.
- 이동·복사·정리(요구사항 §2.3)는 채팅으로 지시하고, 실행은 Run card + 필요하면 Approval card. 파일 찾기 화면에서 직접 이동 버튼을 두지 않는다(되돌리기 어려운 일은 에이전트 작업 기록을 남긴다).

## 6. 로그인·기기 연결·재인증

- `.tk-auth`(점 격자 바탕) > `.tk-auth__panel`(한 열 440): 브랜드 → `display` 제목 + 설명 → 카드(패스키 primary lg · Mac 에서 이 기기 승인) + 연결 상태 → 안내 콜아웃 → 아래 한 줄.
- 재인증은 화면이 아니라 Dialog(`--sm`, `data-tk-modal`): 민감 자료 열기·승인·만료된 링크 다시 받기 전에.

## 7. 오류·빈 화면

- 404·500: 헤더 + `.tk-container--sm` 가운데 → 에이전트 아바타 lg → `heading-1` → 한 줄 이유 → 채팅으로 · 다시 시도. 일러스트 없음.
- 세션이 지워졌을 때: "이 세션은 삭제됐어요. 결과물은 보관함에 30일 남아 있어요." + 보관함으로.

## 8. 설정(템플릿 없음, 조립 규칙)

`.tk-screen__body > .tk-container--sm` 안에 `.tk-section`(제목 + 행들). 행은 `.tk-switch--row`·`.tk-field`·`.tk-list--inset`. 섹션 순서: 연결(Mac Studio·이 기기) → 파일 접근(허용된 위치·별도 정책 폴더) → 자동 승인 → 알림 → 보존 → 테마. 정책을 바꾸는 행은 재인증 Dialog 를 거친다. 에이전트가 정책을 바꾸는 화면 경로는 없다(요구사항 §6).
