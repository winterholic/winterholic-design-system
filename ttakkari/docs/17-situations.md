# 17 · 상황 사전: "이럴 땐 이렇게" (Ttakkari)

00 이 "무엇을 쓸까"라면 이 문서는 "이 상황이 왔는데 어떻게 하지"다. A~H 는 범용, **I~R 은 Ttakkari 상황**이다. 여기서 답이 나오면 다른 문서를 열 필요가 없다.

## A. 글자

| 상황 | 이렇게 |
|---|---|
| 세션 제목이 길다 | 헤더 한 줄 말줄임. 전체는 세션 메뉴·사이드바 행(두 줄까지) |
| 파일 이름이 길다 | 목록은 한 줄 말줄임, 뷰어 제목·상세 제목은 전체(줄바꿈) |
| 경로가 길다 | Path 가 앞 단계를 접는다(모바일). 말줄임하지 않는다 |
| 메시지 안 강조 | `**굵게**`. 형광펜(mark)은 검색 히트 전용 |
| 12px 보다 작게 | 없다 |
| 영문 대문자 라벨 | `.tk-eyebrow`(모노). 한국어 그룹 이름은 `label-sm` |
| 해시·ID | `.tk-mono`, 앞 6자 + `…` + 뒤 4자. 상세에 전체 + 복사 |
| 숫자 열 | `.tk-table__num` 또는 `.tk-numeric` |

## B. 색

| 상황 | 이렇게 |
|---|---|
| 민트 글자를 쓰고 싶다(라이트) | `text.agent`(mint.700). 원색은 점·아바타·잉크 면 |
| 에이전트가 한 행동을 버튼으로 강조 | 버튼은 사람이 누르는 것이라 Blue·중립. 에이전트 표시는 배지·점 |
| 성공을 파랑으로 | 민트(`status.success`) |
| 승인이 필요한 것을 빨강으로 | amber. 빨강은 이미 실패·차단된 것 |
| 민감 파일을 빨강으로 | plum(`policy.restricted`). 빨강은 `blocked` |
| 한 화면에 색이 다섯 | 중립 + Blue + Mint + 상태 하나. 파일 글리프·잉크 면은 예외 |
| 다크에서 Blue 버튼이 어둡다 | 의도다. 흰 글자 대비를 지킨다 |

## C. 레이아웃·간격

| 상황 | 이렇게 |
|---|---|
| 13·18px 이 필요 | 12·16 |
| 데스크톱에서 채팅 열이 좁아 보인다 | 760 이 맞다. 넓은 화면은 분할로 결과물을 옆에 |
| 분할에서 채팅이 360 보다 좁아진다 | 분할을 닫는다(손잡이가 그 아래로 못 줄인다) |
| 모바일에서 사이드바 | 헤더 메뉴 → 드로어 |
| 표·코드·로그가 넘친다 | 그 상자만 가로 스크롤 |
| 폼 필드 둘을 나란히 | `.tk-grid--2`(모바일 1열) |
| 키보드가 컴포저를 가린다 | 셸이 `100dvh` 인지, 스크롤이 스레드 안에서만 일어나는지 |

## E. 컴포넌트 조합

| 상황 | 이렇게 |
|---|---|
| primary 둘 | 하나는 secondary |
| 결과물 카드 안에 버튼 셋 | 다운로드 하나. 나머지는 뷰어·더보기 |
| 탭 안에 탭 | 없다 |
| 모바일에서 행동 메뉴 | Sheet(`.tk-sheet__actions`) |

## F. 상태

| 상황 | 이렇게 |
|---|---|
| 300ms 안에 끝나는 로딩 | 아무것도 표시하지 않는다 |
| 버튼 로딩 | `aria-busy="true"` + `disabled`. 폭 유지 |
| 비활성 버튼의 이유 | `aria-disabled` + 툴팁 **+ 화면 안 문장**(터치) |
| 복사 성공 | 버튼이 1.6초 "복사됨" + 알림. 토스트 없음 |
| 다른 화면에서 작업이 끝났다 | Toast(열기) + 탭바 배지 |

## G. 접근성

| 상황 | 이렇게 |
|---|---|
| 포커스 링이 디자인을 해친다 | 지우지 않는다. 촘촘한 곳은 안쪽으로 |
| 아이콘만 있는 버튼 | `aria-label` |
| 스트리밍이 스크린 리더에서 시끄럽다 | 진행 중 메시지에 `aria-busy="true"`, 끝나면 뗀다 |
| 스크롤 컨테이너 | `tabindex="0"` + `aria-label` |

| 상황 | 이렇게 |

| 다크에서만 색을 바꾸고 싶다 | 컴포넌트 분기 금지. 시맨틱 다크 값을 고친다(15 §2) |
| 히어로 글자가 뒤집힌다 | 원시 `base.white` 로 고정 |

## I. 지시·대화

| 상황 | 이렇게 |
|---|---|
| 에이전트가 생각 중(첫 글자 전) | `.tk-thinking`: live 점 + 무엇을 하는지 한 줄 |
| 스트리밍 중 | 본문 끝 `.tk-caret`(정지). 받은 대로 바로 그린다 |
| 응답이 길다(코드 200줄) | 채팅 안 코드 블록 `data-collapsible`(480 에서 접힘) + 결과물로 저장해 작업 공간에 |
| 에이전트가 표를 냈다 | 작으면 prose 표, 크면 CSV·XLSX 결과물 |
| 사용자가 실행 중에 또 지시 | 받는다. 대기열 배지(`queued` "대기 · 1번째") |
| 같은 지시 다시 | 메시지 행동의 다시 실행. 이전 결과물은 남긴다 |
| 지시를 보내지 못했다 | 말풍선 `data-failed` + 이유 + 다시 보내기. 초안은 지우지 않는다 |
| 제안 칩이 위험한 일(삭제) | 칩은 채우기만 한다. 실행은 사람이 보내야, 위험하면 승인까지 |

## J. 실행

| 상황 | 이렇게 |
|---|---|
| 진행률을 모른다 | 막대 없이 단계만 |
| 단계가 30개 | 지금 단계 ±2 + "단계 30개 중 12번째" + 접힘 |
| 실행이 오래 걸린다(10분) | 경과(모노) + 지금 단계. 다른 화면으로 가도 계속, 끝나면 Toast |
| 사용자가 멈췄다 | `cancelled`. 멈추기 전까지 한 일과 되돌린 것을 단계에 |
| 에이전트가 사람의 입력을 기다린다(질문) | `waiting` + 에이전트 메시지에 질문 + 컴포저로 답 |
| 실패 | 배지 + 실패 단계 `step__detail` + 다시 할 행동 하나 |

## L. 결과물·뷰어

| 상황 | 이렇게 |
|---|---|
| 미리보기를 만드는 중 | 상태 패널 `converting` + 원본 다운로드는 지금 가능 |
| 변환 실패 | `failed` + 원본 다운로드(primary) + 다시 변환 |
| PPTX·DOCX 미리보기 | Notice "변환한 미리보기예요. 원본과 다를 수 있어요" |
| 파일이 너무 크다 | `too-large` + 부분 보기 + 에이전트에게 요약 시키기 |
| HTML 에 스크립트가 있다 | 기본 꺼짐. "스크립트 허용…" 을 눌러야 `allow-scripts` 만 |
| 이미지가 투명 | 체커 바탕(Stage) |
| 모바일에서 결과물 열기 | 전체 화면 뷰어. 새 탭 아님 |
| 보면서 고쳐 달라고 하고 싶다 | 뷰어 아래 후속 지시 컴포저 |
| 결과물을 지웠다 | 보관함에서 지우면 보존 기간 동안 복구 가능(문구로 알린다) |
