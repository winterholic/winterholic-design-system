지난주 회의 결정 사항 요약

10월 첫째 주 회의 3건(기획 · 개발 · 운영)에서 나온 결정 사항 7건을 모았습니다. 담당자가 정해지지 않은 2건은 표에 따로 표시했습니다.

  1. 모바일 PWA 1차 범위는 채팅과 Markdown·PDF 미리보기까지로 한다.
  2. 파일 다운로드는 파일 ID 기반 링크만 쓰고, 링크는 10분 뒤 만료한다.
  3. 외부 메일 발송은 매번 승인한다. 자동 승인은 개인 작업 영역 안에서만.
  4. 회사 자료 폴더는 이번 분기 연동 범위에서 뺀다.

5. 변환 미리보기(PPTX·DOCX)는 원본과 레이아웃이 다를 수 있다는 안내를 항상 붙인다.

6. 결과물 보존 기간 기본값은 30일, 고정한 결과물은 무기한.

7. 실행 로그는 세션이 끝나도 90일 보관한다.
