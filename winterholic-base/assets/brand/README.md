# winterholic 브랜드 자산

사용 규칙은 [`../../docs/14-brand-assets.md`](../../docs/14-brand-assets.md), 통합 미리보기는 [`../../examples/preview.html`](../../examples/preview.html)의 브랜드 자산 섹션을 본다.

## 이미지 생성 방식

- 도구: OpenAI 내장 이미지 생성
- 캐릭터: 투명 RGBA PNG, 1145×1374
- 히어로: RGB PNG, 1672×941

### 캐릭터 최종 프롬프트

> Create a single original friendly ice-crystal spirit mascot for winterholic-base. Use a compact rounded full-body character with a clean six-point snow-crystal head silhouette, simple dot eyes, a subtle confident smile, short limbs, and a Twilight Indigo scarf. Use Bright Snow, Steel Blue, Frozen Lake, Pearl Aqua, and Twilight Indigo. Polished flat vector-like brand illustration, crisp geometric forms, strong silhouette, no text, no shadow, no reflection, no extra characters. Generate against a perfectly flat removable chroma-key background and preserve clean separated edges.

### 히어로 최종 프롬프트

> Create a wide premium winter brand landscape for winterholic-base: a monumental geometric six-point ice crystal hovering above a frozen lake, restrained aurora ribbons, fine snow, and generous quiet negative space on the left. Use Twilight Indigo, Steel Blue, Frozen Lake, Pearl Aqua, and Bright Snow. Polished editorial vector-like illustration, calm and technical, no text, no people, no watermark, no busy scenery.
