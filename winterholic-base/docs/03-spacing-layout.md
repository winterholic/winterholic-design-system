# 03 · 간격·레이아웃

## 1. 4px 그리드

모든 margin·padding·gap 은 `space.*` 중 하나다. 이름은 4px 배수(`space.4` = 16px).

| 토큰 | px | 언제 |
|---|---|---|
| `0-5` | 2 | 아이콘과 글자 사이 미세 조정, 토글 안쪽 패딩 |
| `1` | 4 | 배지 내부, 인라인 요소 사이, 드롭다운 안쪽 패딩 |
| `1-5` | 6 | 인풋↔도움말, 툴팁 상하 패딩 |
| `2` | 8 | **밀접한 것 사이**: 아이콘↔라벨, 라벨↔인풋, 버튼 그룹(sm) |
| `3` | 12 | 컴포넌트 내부 패딩(sm 버튼 좌우·리스트 아이템 상하), 카드 제목↔본문, 버튼 그룹(md) |
| `4` | 16 | **기본 단위**: md 컨트롤 좌우 패딩, 폼 필드 사이, 작은 카드 패딩, 모바일 화면 여백 |
| `5` | 20 | 카드 패딩(기본), 모달 패딩(모바일) |
| `6` | 24 | 큰 카드·모달 패딩, 관련 블록 사이, 데스크톱 그리드 gap, 태블릿 화면 여백 |
| `8` | 32 | 섹션 내부 그룹 사이, 앱 섹션 사이(모바일), 데스크톱 화면 여백 |
| `10` | 40 | 폼 섹션 사이 |
| `12` | 48 | 앱 섹션 사이(데스크톱) |
| `16` | 64 | 랜딩 섹션 사이(모바일) |
| `20` | 80 | 랜딩 히어로 상하 |
| `24` | 96 | 랜딩 섹션 사이(데스크톱) |
| `32` | 128 | 랜딩 대형 섹션 |

13px, 18px, 25px 이 나오면 잘못 잡은 것이다. 디자인 시안에 그런 값이 있으면 가까운 스케일로 올림한다.

## 2. 간격 고르는 원칙 — 가까운 것은 가깝게

간격은 **관계의 거리**다. 같은 그룹은 좁게, 다른 그룹은 넓게. 세 단계면 충분하다.

```
[라벨]            ← space.2 (8)   라벨과 인풋은 한 덩어리
[  인풋  ]
                  ← space.4 (16)  다음 필드
[라벨]
[  인풋  ]
                  ← space.8 (32)  다른 섹션
━━━━━━━━━━━━━━
```

- 안쪽 패딩 ≤ 바깥 간격. 카드 패딩 20px 인데 카드 사이가 12px 이면 카드가 서로 붙어 보인다.
- 세로 리듬은 한 화면에서 세 값 이하로 유지한다(예: 8 · 16 · 32).
- 컴포넌트 안에서는 `padding`, 컴포넌트 사이에서는 부모의 `gap`. 자식에 `margin-bottom` 을 주지 않는다(마지막 요소 예외 처리가 생긴다).

## 3. 화면 골격

### 컨테이너
| 토큰 | px | 언제 |
|---|---|---|
| `container.sm` | 640 | 로그인·회원가입·단일 폼·온보딩 |
| `container.md` | 768 | 문서·설정·읽기 위주 |
| `container.lg` | 1024 | 일반 콘텐츠 |
| `container.xl` | 1280 | **앱 기본**. 대시보드·표 |
| `container.2xl` | 1440 | 와이드 대시보드 전용 |
| `container.prose` | 720 | 본문 글 한 줄 폭 |

```css
.page { max-width: var(--wh-size-container-xl); margin-inline: auto; padding-inline: var(--wh-size-layout-page-gutter); }
@media (min-width: 768px)  { .page { padding-inline: var(--wh-size-layout-page-gutter-md); } }
@media (min-width: 1024px) { .page { padding-inline: var(--wh-size-layout-page-gutter-lg); } }
```

### 화면 좌우 여백(gutter)
| 화면 | 토큰 | px |
|---|---|---|
| 모바일 (< 768) | `layout.page-gutter` | 16 |
| 태블릿 (768 이상) | `layout.page-gutter-md` | 24 |
| 데스크톱 (1024 이상) | `layout.page-gutter-lg` | 32 |

모바일에서 좌우 16px 은 줄이지 않는다. 가로 스크롤은 어떤 화면에서도 나오지 않아야 한다.

### 고정 요소
| 요소 | 토큰 | px |
|---|---|---|
| 헤더 모바일 / 데스크톱 | `layout.header` / `header-lg` | 56 / 64 |
| 사이드바 펼침 / 접힘 | `layout.sidebar` / `sidebar-collapsed` | 240 / 64 |
| 그리드 gap 모바일 / 데스크톱 | `layout.grid-gap` / `grid-gap-lg` | 16 / 24 |

### 브레이크포인트 (min-width, 모바일 퍼스트)
| 이름 | px | 대표 전환 |
|---|---|---|
| `sm` | 640 | 1열 → 2열 카드 |
| `md` | 768 | 태블릿. 헤더 64, gutter 24, display 축소 해제 |
| `lg` | 1024 | 사이드바 고정 노출, gutter 32, 2열 → 3열 |
| `xl` | 1280 | 컨테이너 최대 도달 |
| `2xl` | 1536 | 와이드 대시보드만 반응 |

Tailwind 기본과 같다. 프리셋의 `screens` 가 이 값을 그대로 내보낸다.

## 4. 대표 레이아웃 공식

### 앱 셸 (사이드바 + 헤더 + 콘텐츠)
```
lg 이상: [사이드바 240] [헤더 64 / 콘텐츠 (gutter 32, max 1280)]
md:      [헤더 64 + 햄버거] [콘텐츠 gutter 24]   사이드바는 드로어
모바일:  [헤더 56] [콘텐츠 gutter 16] [하단 탭바 56 (선택)]
```
콘텐츠 상단 여백 = `space.6`(24). 페이지 제목(`heading-1`) 아래 `space.6`, 첫 섹션 시작.

### 카드 그리드
```css
.grid { display: grid; gap: var(--wh-size-layout-grid-gap); grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); }
@media (min-width: 1024px) { .grid { gap: var(--wh-size-layout-grid-gap-lg); } }
```
카드 최소 폭 280px. 이보다 좁으면 카드 안 글자가 세 줄로 접힌다.

### 폼
- 라벨 위, 인풋 아래(가로 배치 금지 — 모바일에서 깨진다).
- 라벨↔인풋 `space.2`, 인풋↔도움말 `space.1-5`, 필드↔필드 `space.4`, 섹션↔섹션 `space.10`.
- 한 줄에 두 필드(이름/성, 시/도)는 `gap: space.4`, 모바일에선 세로로.
- 폼 최대 폭 `container.sm`(640). 인풋이 1000px 로 늘어나지 않게 한다.
- 제출 버튼: 폼 하단 우측(데스크톱), 전폭 `control.lg`(모바일).

### 랜딩
- 섹션 상하 `space.16`(모바일) / `space.24`(데스크톱). 히어로는 `space.20` 이상.
- 섹션 안 제목↔본문 `space.4`, 본문↔CTA `space.8`.
- 컨테이너 `container.lg`(1024) 로 앱보다 좁게 — 읽는 화면이다.

### 리스트·표
- 리스트 아이템 상하 패딩 `space.3`(12), 좌우 `space.4`. 구분선 `border.subtle`.
- 표 행 높이 `component.table.row-height-default` 44px. 밀도 높으면 36, 아바타 있으면 56.
- 표는 가로 스크롤 컨테이너에 넣는다. 모바일에서 표를 카드 리스트로 바꾸는 건 열이 4개 이상일 때.

## 5. 정렬 규칙

- 텍스트는 왼쪽 정렬. 가운데 정렬은 랜딩 히어로·빈 상태·확인 다이얼로그에서만.
- 숫자 열은 오른쫀 정렬 + `numeric` 스타일.
- 버튼 그룹: 데스크톱은 우측 정렬, 주 버튼이 **오른쪽**(취소 · 저장). 모바일 세로 쌓기는 주 버튼이 **위**.
- 아이콘과 글자는 `align-items: center`. 여러 줄 글자 옆 아이콘은 첫 줄에 맞춰 `align-items: start` + 아이콘 `margin-top: 0.125em`.

## 6. 하지 말 것 → 대신

| ❌ | ✅ |
|---|---|
| `margin: 10px` | `space.2`(8) 또는 `space.3`(12) |
| 카드 패딩 24, 카드 사이 gap 8 | 패딩 20, gap 16 이상. 안쪽 ≤ 바깥 |
| 자식마다 `margin-bottom: 16px` | 부모 `display: flex; flex-direction: column; gap: var(--wh-space-4)` |
| 모바일 좌우 여백 8px | 16px 고정 |
| 컨테이너 없이 1920px 전폭 표 | `container.xl` 안에서 가로 스크롤 |
| 라벨을 인풋 왼쪽에 | 라벨 위 |
| 폼 인풋 전폭 1200px | 폼 컨테이너 640 |
| 섹션 사이 간격을 눈대중으로 | 앱 32/48, 랜딩 64/96 고정 |
