# 11 · 데이터 시각화

## 1. 색

| 토큰 | 언제 |
|---|---|
| `chart.categorical.1` 부터 `8` | 서로 다른 범주(제품 A·B·C). **순서대로** 쓴다. 시리즈 3개 이하면 1·2·4(파랑·민트·노랑)가 가장 잘 갈린다 |
| `chart.sequential.1` 부터 `8` | 크기 순서가 있는 값(히트맵·단계 구분도). 밝음 → 어두움 = 작음 → 큼 |
| `chart.diverging.negative / mid / positive` | 기준점 양쪽(손익·증감). 빨강 ← 회색 → 파랑 |
| `chart.grid` / `axis` / `label` | 격자·축선·축 라벨 |
| `action.primary.bg` | 단일 시리즈 차트의 그 한 색 |
| `status.<s>.solid` | 상태를 뜻하는 값(성공률 초록, 오류율 빨강). 범주 구분에 상태색을 쓰지 않는다 |

categorical 순서: 1 Steel Blue · 2 Pearl Aqua(teal.400) · 3 indigo.700 · 4 amber.300 · 5 purple.500 · 6 pink.400 · 7 red.500 · 8 green.500. 7·8 은 상태색과 겹치니 상태 의미가 있는 차트에서는 6개까지만.

다크에서는 같은 토큰이 밝은 단계로 바뀐다. 컴포넌트에서 분기하지 않는다.

## 2. 차트 고르기

| 묻는 것 | 차트 |
|---|---|
| 시간에 따른 변화 | 선(line). 시리즈 4개 이하. 5개 넘으면 소형 다중(small multiples) |
| 범주 간 크기 비교 | 가로 막대(라벨이 길 때) 또는 세로 막대(시간 축일 때). 0 에서 시작 |
| 전체 중 비율 | 누적 가로 막대 1개 또는 도넛(범주 5개 이하). 파이는 쓰지 않는다 |
| 분포 | 히스토그램·박스플롯 |
| 두 변수 관계 | 산점도 |
| 단일 수치 | 스탯 타일(숫자 + 라벨 + 증감) |
| 진행률 | 프로그레스 바. 원형 게이지는 대시보드 요약 1~2개까지 |

## 3. 규격

| 요소 | 값 |
|---|---|
| 축 라벨 | `caption`(12) `chart.label` |
| 축선 | `chart.axis` 1px, y축 선은 생략 가능 |
| 격자 | `chart.grid` 1px, 가로만. 세로 격자 없음 |
| 선 두께 | 2px, 강조 시리즈 3px, 비교(배경) 시리즈 1px `neutral.300` |
| 점 | 기본 숨김, hover 시 6px + 흰 테두리 2px |
| 막대 간격 | 막대 폭의 40%. 그룹 막대는 그룹 안 2px |
| 막대 radius | 위쪽 `radius.xs` (4) 또는 없음. 둘 중 하나로 통일 |
| 범례 | 차트 위 오른쪽 또는 아래, `caption`, 색 칩 12×12 `radius.xs`. 시리즈 1개면 범례 없음 |
| 툴팁 | 06 §9 규격. 날짜 제목 + 시리즈별 "색칩 이름 값". 숫자 `numeric` |
| 여백 | 차트 컨테이너 패딩 `space.4`, 카드 안에서는 카드 패딩만 |
| 최소 높이 | 카드 안 240, 전폭 320 |

## 4. 스탯 타일 (KPI)

```
[라벨 caption text.secondary]
[숫자 display-sm numeric text.primary]   [증감 배지 label-sm]
[비교 문구 caption text.tertiary: "지난주 대비"]
[스파크라인 40px 높이, 선 1.5px action.primary.bg, 채움 8%]  ← 선택
```
- 증감: 상승 `status.success.text` + `trending-up`, 하락 `status.danger.text` + `trending-down`, 변화 없음 `text.tertiary` + `minus`. **좋은 방향이 하락인 지표(오류율·비용)는 색을 반대로.**
- 숫자 축약: 1,234 · 12.3K · 1.2M. 소수 한 자리. 통화는 원 단위 그대로 쉼표.
- 타일 4개가 한 줄(데스크톱), 2개(태블릿), 1개(모바일). 간격 `space.4`.

## 5. 접근성

- 색 + 다른 신호: 선 차트는 마커 모양 또는 직접 라벨(선 끝에 시리즈 이름), 막대는 순서와 라벨.
- 차트마다 `<figcaption>` 또는 `aria-label` 로 한 문장 요약("9월 방문자 12% 증가").
- 표 대안: 차트 데이터를 `<table>`(시각적으로 숨김 또는 토글)로 제공.
- 애니메이션(그려지는 효과)은 `slow` 300ms 한 번, reduced-motion 이면 없음.

## 6. 하지 말 것 → 대신

| ❌ | ✅ |
|---|---|
| 파이 차트 8조각 | 가로 막대 정렬 |
| y축 0 이 아닌 곳에서 시작한 막대 | 0 시작. 차이를 보이려면 선 차트 |
| 3D·그림자·그라데이션 채움 | 단색 평면. 영역 채움은 8% 이내 |
| 시리즈마다 랜덤 색 | `chart.categorical` 순서 |
| 격자 가로+세로 촘촘 | 가로 4~5줄 |
| 범례에서 색 찾아 읽게 | 선 끝 직접 라벨 |
| 이중 y축 | 차트 두 개 |
| 상태색으로 범주 구분(초록=A, 빨강=B) | categorical 1·2 |
