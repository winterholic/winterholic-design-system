# 16 · 상황 사전 — "이럴 땐 이렇게" (winterholic-base)

00 결정표가 "무엇을 쓸까"라면, 이 문서는 "이 상황이 왔는데 어떻게 하지"다. 개발하다 막히는 지점을 상황별로 미리 답했다. 파생 시스템(stock-gosu·memoir)의 16 은 이 골격에 도메인 상황을 더한 것이다.

## A. 글자

| 상황 | 이렇게 |
|---|---|
| 제목이 길어 두 줄로 접힌다 | 허용(snug 1.3). 세 줄이면 문구를 줄이거나 2줄 clamp + 툴팁 |
| 카드 설명이 길다 | `-webkit-line-clamp: 2` + 상세에서 전체 |
| 표 셀 텍스트가 넘친다 | 1줄 말줄임 + `title`. 열 폭은 줄이지 않는다 |
| URL·긴 영문이 상자를 뚫는다 | 전역 `overflow-wrap: anywhere` 가 처리. 코드는 가로 스크롤 |
| 숫자 정렬이 흔들린다 | `.wh-numeric`(tabular) + 우측 정렬 |
| 12px 아래 글자가 필요 | 없다. 2xs 11 이 하한(법적 고지·배지). 정보를 줄인다 |
| 본문 안 강조 | `<strong>` = medium 500. bold 는 튄다 |
| 한 화면에 제목 4단계 | 3단계까지. h1 → h3 → h5 건너뛰기 허용, 태그와 클래스 분리 |
| 영문 대문자 라벨 | `.wh-overline`(11/600 +0.04em). 한글에는 자간만 |
| 인풋 글자 14px 모바일 확대 | 인풋은 16(`input.md`) |
| 날짜·시간 | `2026.09.18` `14:30`, 상대 시간 7일까지 |
| 음수 | `−`(U+2212) |
