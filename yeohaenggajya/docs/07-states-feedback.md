# 07 · 상태와 피드백 (여행가쟈) — 로딩 · 빈 상태 · 오류 · 확인 · 카피

카피 톤은 원본 `references/copy-and-a11y.md` 가 정본이다. 여기서는 화면 상태별로 **무엇을 보여주고 어떤 문구를 쓰는지** 를 한 표로 모았다.

| 상태 | 언제 | 표시 |
|---|---|---|
| 첫 로딩 | 화면 진입 | CardShell·hanji-2 정지 스켈레톤(shimmer 없음) |
| 재조회 | 필터·탭 변경 | 기존 유지 + 헤더 아래 2px 빨강 progress |
| 가챠 진행 | 굴리는 중 | 무대 연출(05 §4). 스피너 없음 — 캡슐이 로딩 표시다 |
| 남은 횟수 0 | 1일 10회 소진 | GachaCta disabled + "내일 다시 굴릴 수 있어요". 결제 유도 없음 |
| 빈 상태 | 0건 | §2 |
| 카메라·모델 준비 실패(AR) | MediaPipe 실패 | "카메라를 못 열었어요" + "직접 던지기" 버튼 fallback |
| 오프라인 | | `/offline` 페이지 + 로컬 도감 유지. "오프라인이에요. 뽑은 캡슐은 여기 있어요" |
| 위치 없음 | 좌표 없는 장소 | 방문 인증 버튼 미노출(빈 자리·"정보 없음" 금지) |
| visitorNote 없음 | 데이터 공백 | 요소 자체 미렌더 |
| 비로그인 | 관심·인증 | 로컬 저장 + "계정을 연결하면 어디서든 볼 수 있어요" 안내 링크 |
| 오류 | 요청 실패 | §3 |
| 성공 | 뽑기·인증·공유 | §5 |

## 1. 로딩
- 300ms 안에 오면 표시 없음.
- 스켈레톤은 hanji-2 단색 정지. 종이는 깜빡이지 않는다.
- 카드 자리는 `CardShell`(등급 미정이면 common 프레임).
- 가챠는 연출 자체가 대기 시간(3~5s). 서버가 늦으면 여정을 늘리되 8s 넘기면 "캡슐이 막혔어요" 오류.
- 이미지(관광공사 사진) 로딩: hanji-2 자리 + 로드 후 fade `normal`. 실패 시 민화 플레이스홀더 일러스트(회색 X 아이콘 금지).

## 2. 빈 상태 — 빈 화면도 안내한다
```
캡슐 sm 72 (정지, common)          ← 위 48
heading-sm "아직 뽑은 캡슐이 없어요"   ← 아래 8
body "첫 캡슐을 굴려봐요"             ← 아래 24
red md "캡슐 굴려요"
```
| 화면 | 제목 | 액션 |
|---|---|---|
| 도감(뽑은 카드) | "아직 뽑은 캡슐이 없어요" | "캡슐 굴려요" → 홈 |
| 도감(세트) | "모으는 중인 세트가 없어요" | "세트 둘러보기" |
| 인증 완료 | "다녀온 곳을 인증해봐요" | "가까운 곳 찾기" |
| 코스 | "이 캡슐엔 아직 코스가 없어요" | "다른 코스 보기" |
| 방(멀티) | "함께 굴릴 친구를 불러요" | "까치 보내기" |
| 검색·필터 0 | "이 조건엔 캡슐이 없어요" | "필터 지우기" |
| 최근 장소 | "최근 다녀온 곳이 여기 쌓여요" | 없음 |
| 공유 만료 | "이 캡슐은 이제 볼 수 없어요" | "나도 굴려보기" |

도감 빈 셀은 회색 빈칸이 아니라 **일러스트 자리**(CardShell + 도장 실루엣).

## 3. 오류
| 수준 | 표시 | 문구 |
|---|---|---|
| 필드 | 테두리 red-deep + 도움말 danger + `aria-invalid` | "이메일 형식이 아니에요" |
| 동작 | 토스트(미구현이면 인라인) 2.8초 | "앗, 캡슐이 막혔어요 · 잠시 후에 다시 굴려볼까요" |
| 섹션 | 그 카드만: 캡슐 xs + 문구 + ghost sm "다시 시도" | "여기만 잠깐 막혔어요" |
| 페이지 | 빈 상태 형태 + 오류 ID mono | "앗, 길을 잃었어요" |
| 가챠 실패 | 무대에서 한지로 복귀 + 다이얼로그 | "캡슐이 막혔어요. 횟수는 안 줄었어요" (횟수 보존 명시) |
| 카메라 | 인라인 + fallback 버튼 | "카메라를 못 열었어요. 직접 던져볼까요?" |

문구 공식 [무엇이] + [왜] + [어떻게]. 사과 남발 금지("죄송합니다" 반복 X). 시스템 코드는 mono 작게 뒤에. 오류에도 가챠 어휘("막혔어요", "굴려볼까요").

## 4. 확인 다이얼로그 (되돌릴 수 없는 것만)
| 행동 | 확인 |
|---|---|
| 첫 뽑기 | 없음(스킵 불가 연출이 곧 확인) |
| 뽑기(횟수 소진) | 없음. 버튼 자체가 명확("캡슐 굴려요") |
| 방 나가기 | 다이얼로그: "방을 나갈까요?" · "닫기" / "나가기"(blue) |
| 기록 삭제·계정 연결 해제 | 다이얼로그: "뽑은 캡슐 12개가 사라져요" · "닫기" / "지우기"(danger) |
| 방문 인증 취소 | 없음. 토스트 "되돌렸어요" |
왼쪽은 항상 "닫기". 오른쪽은 동작 이름. "예/아니오/확인" 금지. 파괴면 첫 포커스 닫기.

## 5. 성공
| 행동 | 피드백 |
|---|---|
| 뽑기 | 무대 연출 → 카드 → BannerRank "전설의 발견이에요!" |
| 도감 수집 | 셀 도장 찍힘(scale 1.2→1) + 토스트 "짠— 도감에 담았어요" |
| 방문 인증 | 도장 + "다녀왔어요 도장 꽝!" |
| 공유 링크 복사 | 버튼 → check 1.5초 + "까치가 날아갔어요" |
| 세트 완주 | BannerRank 형식 + "한 세트 다 모았어요" |
| 계정 연결 | "이제 어디서든 도감을 볼 수 있어요" |

## 6. 비활성 vs 숨김
- 횟수 0 → CTA 비활성 + 이유. 숨기지 않는다.
- 좌표 없는 장소의 인증 → 숨김(빈 자리 금지 규약).
- 비로그인 관심·방 → 활성 + 누르면 로컬 저장 또는 계정 연결 안내.
- 2FA 같은 권한 개념 없음. 관리 화면 없음.

## 7. 카피 — 굴리다 + 까치 + 옛이야기 (원본 copy-and-a11y §A)
- 해요체 + 가챠 어휘(굴리다·캡슐·짠·까치·민화·도깨비·호랑이) + 현대 친근 어투(~봐요/예요/하실래요).
- **금지 3종**: 사극("~하옵나이다") · SNS("역대급 갓성비") · 게임("★LEGENDARY★ 등장!!").
- 등급명은 한국어 문장에("전설의 발견이에요"). 영문은 Cinzel 라벨에만.
- 브랜드명 **여행가쟈**(로고·매니페스트·메타). 뽑기 일반명사는 "가챠".
- 캡슐 메타포 유지("캡슐 굴려요"). 방망이 메타포 폐기.
- 토스 5원칙: 해요체·능동("했어요")·긍정("있어요")·캐주얼 경어("~시겠어요?" 금지)·명사+명사 풀기.
- 다이얼로그 왼쪽 "닫기". CTA 는 결과가 보이는 문구("여기로 떠나기").
- 등급을 서열로 읽히게 하는 카피 금지("최고 등급!"). 등급은 발견의 결.

| 화면 | 카피 견본 |
|---|---|
| 홈 | "오늘 어디로 가실래요?" · "짠— 새 캡슐이 도착했어요" · "캡슐 굴려요" |
| Prelude | "두근두근— 뭐가 나올까요" · "어, 뭔가 다른데?" |
| 결과 뒷면 / 앞면 | "눌러서 열어요" / "짠— 옛이야기 한 자락!" · "머드철 保寧" |
| Unique | "겨울 철원 · 유일한 발견이에요" |
| visitorNote | "한 해 7만 7천 명만 다녀간 곳" · "지금 축제가 열리는 곳이에요" |
| 공유 | "까치 보내기" · "같이 굴려볼까요" |
| 오류 | "앗, 캡슐이 막혔어요" · "잠시 후에 다시 굴려볼까요" |
| 횟수 소진 | "오늘 캡슐은 다 굴렸어요 · 내일 또 봐요" |
