# 16 · 상황 사전 — "이럴 땐 이렇게" (여행가쟈)

원본 SKILL 의 "막혔을 때" 표는 **규칙 충돌·질의** 중심이다. 이 문서는 그 앞 단계, **시각 상황**을 다룬다. 규칙 충돌·예외 요청·질의 4요소는 원본 표를 따른다(누가·언제·어떻게·기대값, partial success).

## A. 배경·면

| 상황 | 이렇게 |
|---|---|
| 흰 배경이 필요해 보인다 | 없다. `surface.default`(#FBF5E5). 순백은 Bright Line 2 위반 |
| 카드와 배경이 구분 안 된다 | 먹선 2px + `shadow.paper`. 면 색 차이(1.08)로는 안 된다 — 이 시스템은 선으로 구분 |
| 카드 안 구획 | hanji-2 면 또는 hanji-dark 1px 선. 카드 안 카드 금지 |
| 어두운 배경을 쓰고 싶다(히어로·강조) | 무대(`data-tone="dark"`)는 연출만. 한지 화면에서는 ink 면 툴팁·토스트·코드 정도 |
| 단청색으로 섹션 배경 | 금지. 띠 6px 또는 테두리 |
| 선택된 항목 | hanji-2 면 + 빨강 테두리. 파랑 면 아님 |
| 데스크톱에서 화면이 넓다 | 폰 프레임 셸(768 이상) + 책상 격자. 전폭으로 펴지 않는다 |
| 텍스처가 카드에도 보인다 | 캔버스만 텍스처. 카드는 매끈 |
| 시트 뒤가 밝다 | 스크림 ink 60% |

## B. 색

| 상황 | 이렇게 |
|---|---|
| 메타 글자가 옅어 보여 `--ink-4` | 금지(2.49). `text.tertiary`(ink-3 5.17) |
| 노랑·금 글자 | 금지. 띠·글로우·테두리. 글자는 ink |
| jade 로 성공 문구 | 아이콘·테두리만 jade, 문구 ink |
| 빨강 강조 글자 | 14px 800 이상, 카드(bright) 위 4.8. 본문 크기 빨강 금지 |
| 등급을 색으로만 | 풀네임 + 한국어명 + 한자 도장 병기 |
| 홀로색 버튼 | 금지. 홀로는 무대 빛 |
| 무대에서 금 글자 | 허용(10.7). 한지에서는 ink |
| 칩 노랑 글자 안 읽힘 | yellow-deep + 아이콘·600 굵기, 또는 파랑 칩 |
| 새 강조색이 필요 | 원본 `tokens.css` 에 의미 기반 토큰 먼저. 임시는 가장 가까운 단청 + `TODO(design)` |
| 오류 빨강 vs 강조 빨강 | 오류는 red-deep + 아이콘 + 문구, 강조는 red |
| 시스템 다크 요청 | 없음. "이건 Bright Line 2 위반인데 의도된 예외인가? 대안은 무대 톤" 한 줄 질의 |

| 붓글씨를 세 곳 쓰고 싶다 | 두 곳. 나머지 Batang |

| 카피가 375 에서 넘친다 | 문구를 줄인다. 글자 크기 아님 |

## D. 레이아웃·간격

| 상황 | 이렇게 |
|---|---|
| 새 max-width | 기둥 4종(520/720/960/1152) + 셸 430 |
| 본문과 표가 다른 오른쪽 끝 | 한 기둥 |
| 헤더 우측 아이콘 2개 | 1개 + 시트 |
| 하단 CTA 와 탭바 | CTA 가 탭바 위. 본문 하단 패딩 = 둘 + 16 |
| 탭바 4개 항목 | 3개(홈·도감·마이) 고정. 더보기는 마이 안 |
| 도감 375 에서 셀이 안 맞는다 | 16 + 108×3 + 8×2 + 16 = 372 |
| 캡슐이 작아 보인다 | 홈 160(가용 높이 40%). 리스트는 xs 40 |
| 카드 폭 | 200 고정. 상세는 min(280, 100% − 32) |
| 13·15px 간격 | 12/16 스냅 |
| 버튼 사이 | BottomCta gap 8, 인라인 8 |
| 데스크톱 프레임 밖 여백 | 책상 32, 프레임 안 40/48 |
| 시트 높이 | 최대 88vh, 본문 `.hanji-scroll` |
| 폰 프레임에서 sticky | 프레임 안 `overflow: auto` 컨테이너 기준 |

## E. 컴포넌트 조합

| 상황 | 이렇게 |
|---|---|
| 카드 안 버튼 | 카드 클릭이면 `::after inset:0` 링크 + 안 버튼 없음. 필요하면 카드 아래 BottomCta |
| 리스트 행 안 버튼 두 개 | 행 = 링크, 액션은 시트 |
| 칩 10개 | 가로 스크롤 + `hanji-fade` |
| 필터가 많다 | FloatingFinder → 시트 안 칩 그룹 |
| 세트 탭에 필터 버튼 | 없음(걸 필터가 없다) |
| 드롭다운 vs 시트 | 모바일 시트, 데스크톱 프레임 안에서도 시트(폰 어법) |
| 다이얼로그 인풋 | Prompt 없음 → 시트 + TextInput |
| 툴팁 | 없음(터치 우선). 정보는 `info` 아이콘 → 시트 |
| 스켈레톤 개수 | 실제와 같게. 카드 자리는 CardShell |
| 캡슐 + 카드 동시 | 무대 3막에서만 순차. 한 화면에 둘 다 정지 상태로 두지 않는다 |
| 등급 의존 컴포넌트 새로 | 5등급 + moment 전부 정의, 스토리 전부 |
| 아이콘 vs 도장 | 검색·인증·필터는 도장 아트워크, 나머지 Lucide |
| 진행 표시 | 막대(8/4). 링·도넛 없음 |
| 토스트가 없다(미구현) | 인라인 `role="status"` 문구로 대체 + 부채 기록 |
| 공유 버튼 | "까치 보내기" blue |

## F. 등급·연출

| 상황 | 이렇게 |
|---|---|
| Rare 와 Epic 이 비슷해 보인다 | Epic 은 aura 추가 + strong 흔들림. 차이는 분명해야 |
| Unique 연출이 밋밋하다 | 의도. 고요·느린 홀로. Legendary 처럼 만들지 않는다 |
| Legendary 도감 셀 | foil 펄스만. 무지개 없음 |
| 등급 정렬 요청 | 금지(서열 아님). 방문순·계절 |
| 지역에 등급 고정 표시 | 카드 인스턴스 등급. 도감 셀은 뽑힌 카드 등급 |
| visitorNote 데이터 없음 | 요소 미렌더 |
| Unique 시즌 키워드 없음 | 데이터 오류. 표시 보류 + 보고 |
| 연출이 길다 | 공개 1~2s. 여정 5s 상한 |
| 첫 뽑기 건너뛰기 | 불가(의도). 이후 ghost |
| 무대에서 로고 | 없음 |
| reduced-motion 에서 연출 | 흔들림 없이 진행, 등급은 배너 텍스트 |
| moment 등급이 낯설다 | 유일 위 전설 아래, 은박. 찰나의 발견 |

## G. 상태·데이터

| 상황 | 이렇게 |
|---|---|
| 횟수 0 | CTA 비활성 + "내일 다시". 결제·광고 유도 없음 |
| 서버 실패 중 뽑기 | 횟수 보존 명시 다이얼로그 |
| 비로그인 도감 | 로컬 → 없으면 공개 갤러리. 로그인 강요 시트 금지 |
| 오프라인 | `/offline` + 로컬 도감 |
| 카메라 거부 | 직접 던지기 fallback |
| 좌표 없는 장소 인증 | 버튼 숨김(빈 자리·"정보 없음" 금지) |
| 이미지 없음 | 민화 플레이스홀더 |
| 세트 완주 | 배너 + 도장, 위로 올리지 않음(다음 할 일 우선) |
| 방 인원 변동 | `aria-live` 한 곳 |
| 방문 인증 되돌리기 | 토스트 "되돌렸어요", 확인 없음 |

## H. 접근성·구현

| 상황 | 이렇게 |
|---|---|
| `<div onClick>` | `<button>` |
| `<a>` 안 `<button>` | `::after inset:0` |
| 아이콘 버튼 | `aria-label` 단어만("검색") |
| 캡슐 스크린리더 | `role="img" aria-label="Rare 캡슐"` 또는 장식 hidden |
| 오방색 띠 | `aria-hidden` |
| 카드 뒤집기 키보드 | `<button aria-pressed>` Enter/Space |
| 포커스 링 안 보임 | 파랑 2px offset 3, `outline: none` 금지 |
| 새 keyframe | `effects.css` 에, 모듈은 사용만 |
| 외부 위젯(지도 iframe) | 래퍼 경계만 토큰. 내부 강제 안 함 |
| raw hex 를 박고 싶다 | 원본 `tokens.css` 에 토큰 먼저. 급하면 가까운 토큰 + `TODO(design)` |
| references 와 원문(v3.1/v4.1) 충돌 | references(코드 기준)가 이김. 한 줄 남김 |
| 규칙끼리 충돌 | 접근성 > 등급·카피 > 색·배경. 애매하면 한 줄 질의(4요소) |
| 질의 불가(CI) | 보수적 토큰 기본값 + 보류 기록, 나머지는 완성(partial success) |

## 이 사전에 없는 상황이면
1. 원본 SKILL "막혔을 때" 표 → 질의 4요소.
2. 결정했으면 이 문서에 한 줄 + 원본 references 에도 한 줄(드리프트 방지).
